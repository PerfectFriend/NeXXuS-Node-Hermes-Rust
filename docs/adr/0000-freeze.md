# ADR-0000: Заморозка TS-ядра (freeze)

**Статус:** Принят, 2026-11-02.
**Решение владельца:** «погнали» по плану миграции на Rust.

## Контекст
README и `ACCEPTANCE_NEXXUS_CORE_TZ.md` обещают ядро `nexxus-core` на Rust, которого в репозитории нет (`find -name '*.rs'` → 0). Существующее TS-ядро содержит криптографические дефекты (Math.random для мнемоники, словарь 440 слов вместо 2048, фиктивный BIP-32, onion от sha256(privkey)). Починка всех дефектов в TS — это двойная работа перед переносом на Rust.

## Решение
С момента этого коммита **новый функционал пишется только в `crates/`**. TypeScript-код (`src/utils/*.ts`, `scripts/linux-daemon.ts`) замораживается: допускается только hotfix критических багов и правки, нужные для conformance-сверки Rust↔TS (Фаза 7 плана).

## Последствия
- Математическое ядро (RS(4+2), Merkle/PoR, golden-векторы) остаётся источником истины для сверки, пока не будет байт-в-байт воспроизведено в Rust.
- Wire-протокол канонизируется в Rust (ADR-0001); TS-реализация считается эталоном v2 до демонтажа.
