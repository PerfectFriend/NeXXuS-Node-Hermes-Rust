# ADR-0004: Экономика — отдельный крейт, целочисленные деньги

**Статус:** Принят, 2026-11-02. **Решение владельца:** «экономика отдельно».

## Контекст
`storageManager.ts` считает NEXX/TON/USDC в JS `number` (float) — округления уплывут на больших объёмах. Владелец решил вынести экономику из ядра.

## Решение
- Новый workspace-крейт `crates/nexxus-econ` с собственным релиз-циклом и тестами; зависит от `nexxus-core` только через типы (`Money`, `NodeId`).
- `Money(i64)` в микро-NEXX: `1 NEXX = 1_000_000_000`. Все ставки/вестинг/квоты целочисленные, округление half-up. В HTTP API отдаётся строкой, не JSON-number.
- Модули: `sections.rs` (16 GB секции), `vesting.rs` (56 дней, эпохи), `degradation.rs` (14/28 дней), `antiloop.rs` (net yield < 0).

## Последствия
Ядро `nexxus-core` остаётся чистым (только крипто + wire + kad + merkle + rs); экономика не попадает в wasm для браузера автоматически — при необходимости подключается отдельно.
