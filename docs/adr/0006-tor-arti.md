# ADR-0006: Tor — самый новый (arti-client), feature-gated

**Статус:** Принят, 2026-11-02. **Решение владельца:** «tor самый новый».

## Контекст
Текущий код только вычисляет onion-адрес из ключа; реальных onion-соединений нет ни в демоне, ни в клиенте. README это подаёт как реализованный транспорт.

## Решение
- Транспорт через **`arti-client`** (актуальный Rust-стек Tor от Tor Project) под cargo-feature `tor`.
- Демон публикует onion-сервис v3 на локальный WS-порт; исходящие peer-соединения идут через arti.
- Сборка `.deb`: `cargo deb --features tor`. Без флага демон работает по TCP/WS (LAN, CI, тесты).
- Onion-адрес считается по ADR-0001/keys/onion.rs (pubkey‖checksum‖0x03 → base32), и теперь реально используется для соединения.

## Последствия
- arti-client тяжёлый и местами нестабильный → отдельная сборка, отдельный smoke-тест (`docs/tor-smoke.md`).
- Правка README про Tor допускается только после зелёного ручного теста onion-соединения (Фаза 8 плана).
