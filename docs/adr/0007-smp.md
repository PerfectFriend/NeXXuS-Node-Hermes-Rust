# ADR-0007: SMP-мессенджер — реализуем в v2.1

**Статус:** Принят, 2026-11-02. **Решение владельца:** «smp делаем».

## Контекст
`SMP_ENVELOPE (0x0D)` есть в спеке, но не реализован ни в TS-демонах, ни в UI (MessengerView работает на локальных моках). Владелец решил реализовать по-настоящему.

## Решение
- Опкод `0x0D SmpEnvelope` получает бинарный payload (§4 спеки расширить): `sender_node_id[32] || recipient_node_id[32] || nonce[12] || ct_len u32 || ciphertext+tag` — envelope шифруется ключом получателя (X25519 ECDH → ChaCha20-Poly1305), узел-ретранслятор не читает содержимое.
- Маршрутизация envelope через Kademlia: отправка на ближайших узлов к `recipient_node_id`, хранение pending-envelope с TTL.
- Модуль `crates/nexxus-core/src/smp/` + обработчик в демоне; UI MessengerView подключается к `/api/smp/*`.

## Последствия
SMP выходит за рамки исходного «wire каркаса» — добавляется отдельная фаза после Фазы 6 (демон) и перед Фазой 7 (wasm/UI). Требует X25519 (`x25519-dalek`) рядом с Ed25519.
