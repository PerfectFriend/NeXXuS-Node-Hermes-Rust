# ADR-0008: Подпись комитета — multi-sig Ed25519 (не BLS)

**Статус:** Принят, 2026-11-02. **Решение владельца:** «multisig».

## Контекст
`EPOCH_FINALIZE` в спеке имеет `committee_signature` («BLS / Multi-Ed25519»). BLS потребовал бы тяжёлую зависимость (`blst`, pairing-кривые) и отдельную церемонию ключей.

## Решение
- Агрегирование кворума аудиторов = **мульти-подпись Ed25519**: payload эпохи (`epoch_number || merkle_root || total_bytes`) подписывается каждым членом комитета; wire несёт `count u16_be || [pubkey[32] || sig[64]]*`.
- Верификация: не менее `M of N` валидных подписей от адресов из реестра аудиторов (ончейн-мандат через FunC-контракты).
- Реализация в `crates/nexxus-core/src/epoch.rs`; без BLS, без pairing-зависимостей.

## Последствия
Размер кадра EPOCH_FINALIZE растёт линейно с размером комитета (N×96 байт) — при комитете ≤ 20 это ≤ ~2 КБ, приемлемо. Если позже понадобится компактная агрегация — отдельный ADR под BLS, обратно совместимо по версии протокола.
