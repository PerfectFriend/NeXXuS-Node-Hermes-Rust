## Раздача

Канонический артефакт — **squash-mirror** (см. `SECURITY.md`, `docs/DEP-03-secret-rotation.md`).
Self-update: `nexxusd update [--check]` сверяет подпись релиза с зашитым pubkey.

## Известные границы

- Экономика — accounting only (не платежи, не on-chain)
- Windows MSI/service и нативный Android-узел — следующие фазы (roadmap E4/G5)
- Onion для API — опционально, `NEXXUS_API_ONION=1`, token-gated
