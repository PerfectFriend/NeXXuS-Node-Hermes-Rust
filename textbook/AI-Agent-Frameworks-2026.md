## 🎯 Key Frameworks Compared

| Framework | Strength | Best For |
|-----------|----------|----------|
| **LangGraph** | Largest ecosystem, stateful orchestration, Python/JS | Production multi-agent workflows |

| **AutoGPT** | Autonomous experimentation | Research, exploration |

## 🔑 Trends 2026
1. **Graph-based orchestration** (LangGraph) dominates over loop-based
2. **MCP (Model Context Protocol)** — 1000+ servers, standard for tool access
3. **Spec-Driven Development** — GitHub Spec Kit (130k+ stars) makes specs executable
4. **Agent Resource Discovery** — Google's open spec for publishing AI capabilities
5. **Harness engineering** — Evals, memory, permissions, observability as first-class
