The draft model provides significant speedup for structured content (code, math, JSON) but less for prose.\n  2. On Linux, the overhead of the draft model becomes negligible (~0.99×), making the bet almost free.\n  3. For editing tasks (where output is a copy of the prompt with few changes), speculation can yield up to 9.27× speedup when the copied fraction is high.\n  4. ngram-simple (a simple n-gram draft) serves as a safe floor with no regression and up to 9.27× on edits.\n  5. The FRONDE-Router dynamically selects between draft model (aggressive) and ngram-simple (safe) based on a 48-token probe and an EMA collapse detector, maintaining invariants: ≥ baseline on all content types and ≥ 90% of the static champion on code/math/JSON.\n- The project emphasizes correctness: comparisons are bracketed (baseline before + after) to account for thermal drift, and a faster result that damages output is rejected.\n- FRONDE supports multiple backends: llama.cpp (default), with CUDA and Metal acceleration.\n\n## Code Patterns\n```bash\n# From the FRONDE repo\n# 1.
