Настройки уведомлений — Telegram

—

Токен хранится только локально в ~/.nexxus/telegram.json (права 0600) и никогда не попадает в логи и git. Приоритет: env → этот файл → secrets.

Идентичность — BIP39 сид-фраза

—

Сид-фраза показывается один раз по запросу и никогда не пишется в логи. Запишите 12 слов в надёжном месте — без них узел не восстановить.

Зашифрованный бэкап сида (seed.vault)

—

Бэкап — AES-256-GCM (PBKDF2 600k), файл *.seed.vault рядом со стором, права 0600, формат совместим с SDK. Сид в открытом виде — только внутри зашифрованного файла.

Бэкапы хранилища (R3)

—

Бэкап — копия файла стора (redb CoW, безопасно на живой ноде) + манифест sha256/merkle. API никогда не затирает живой стор: восстановление готовит *.restore-candidate.redb, подмена — nexxusd restore <name> при остановленном демоне.
