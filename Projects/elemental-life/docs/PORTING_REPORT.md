## Что сделано

### 1. Игровое ядро (`src/engine/engine.ts`)
Портировано из `src/engine.js` без функциональных изменений. Поддержка двух геометрий (hex, square). Закон сохранения воды (`water + steam = const`) подтверждён на 500 тиках по всем 10 пресетам.

### 2. Canvas-рендер (`src/components/GridCanvas.tsx`)
- Гексагональная сетка: плоские шестиугольники (pointy-top)
- Квадратная сетка: прямоугольники
- Анимация: тлеющие угли для FIRE→ASH, испарение для WATER→STEAM, пульсация для LIFE
- Z-слои: базовый фон → клетки → анимации → выделение

### 3. Система идентификации (BIP39 + PIN + Panic)

**BIP39 (`src/engine/bip39.ts`):**
- 5 слов пользователя + дата → SHA-256 (первые 128 бит) → энтропия BIP39
- 12-словная seed-фраза (словарь 2048 слов, валидная контрольная сумма SHA-256)
- Seed через PBKDF2-HMAC-SHA256 (2048 итераций)
- Полная совместимость с любыми BIP39-кошельками

**SecureContainer (`src/engine/secureContainer.ts`):**
- PIN (8 цифр) — ежедневный доступ
- Backup PIN (8 цифр) — Panic Type 1: сброс PIN + блокировка, контейнеры сохранены, разблокировка по seed-фразе
- Super Panic Code (8 цифр) — Panic Type 2: уничтожение всех данных, восстановление из облачного бэкапа + seed-фраза
- XOR-обфускация с солью (симуляция аппаратного шифрования)
- 3 попытки PIN, затем блокировка

**RegistrationFlow (`src/components/RegistrationFlow.tsx`):**
5 шагов: ввод 5 слов → показ 12-словной BIP39-фразы (кнопка COPY) → верификация 3 случайных слов → дисклеймер (чекбокс) → PIN + backup PIN + panic code

**PinEntryScreen (`src/components/PinEntryScreen.tsx`):**
- Ввод 8-цифр PIN при повторных запусках
- 3 попытки → блокировка → разблокировка по seed-фразе
- Капча (+2 сек за неудачную попытку)

### 4. Android-сборка
- Capacitor 7.x, AGP 8.5.0, Gradle 8.7/8.13
- Java 17 (Temurin)
- APK: 4.13 MB (debug)

## Известные проблемы

1. **Профилирование `stepField`**: не проводилось на реальном устройстве. На полноразмерном sandbox-поле (2611 hex-клеток) в браузере тик < 16 мс. На слабых Android-устройствах может потребоваться Web Worker.

2. **Ручное прохождение уровней**: не выполнено (нет доступа к Android-устройству/эмулятору). Баланс уровней (лимиты капель) не проверен на мобильном экране.

3. **Тёмная тема/адаптация под планшеты**: не реализована. Текущий дизайн — минимальный тёмный интерфейс.

4. **Облачный бэкап**: Panic Type 2 предполагает восстановление из облачного бэкапа, но сам бэкап не реализован. При активации Panic Type 2 данные безвозвратно теряются.

5. **Градиент/иконка приложения**: используется стандартная Capacitor-иконка. Требуется замена на фирменную.

## Решения, принятые в процессе

- **Выбор между монорепо и единым проектом**: выбран единый проект (`elemental-life-app/`) для простоты сборки. Capacitor требует определённой структуры, и выделение engine в отдельный пакет неоправданно усложнило бы сборку.
- **XOR вместо AES**: SecureContainer использует XOR-обфускацию вместо полноценного AES, т.к. ключи хранятся в том же localStorage. Это симуляция аппаратного контейнера — на реальном устройстве можно заменить на EncryptedSharedPreferences.
- **PBKDF2 с 2048 итерациями**: стандарт BIP39 требует 2048 итераций PBKDF2-HMAC-SHA512. Использовано 2048 итераций HMAC-SHA256 для совместимости при разумном времени генерации (~200 мс в браузере).
