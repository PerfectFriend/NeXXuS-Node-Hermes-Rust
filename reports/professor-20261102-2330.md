## Ключевые инсайты для Машины Кода

### 1. **Self-HPO = Наш Professor→Coder→Auditor Loop**
- **H-step** (Professor): failure analysis → harness proposals
- **P-step** (Coder/Auditor): RL/execution under new harness
- **Hard tasks** from P-step → next H-step search set
- **Joint gain > sum of parts** — не оптимизировать harness и policy изолированно

### 2. **RRSI = Regularization для Harness Evolution**
- **Critic Gate** (pre-evaluation): leakage screen (regex + LLM)
- **Noise-Adjusted Floor**: bootstrap delta, блокирует gains within variance
- **Annealed Edit Budget**: уменьшающийся scope предложений со временем
- **Edit History + Tried Set**: не перепредлагать falsified hypotheses
- **Pruner**: удаляет too-small/expensive/stale components
- **Git Worktrees**: изолированная оценка кандидатов

### 3. **RiseHarness = Flipping Tasks + Harness Handbook**
- **Flipping tasks** = задачи с mixed pass/fail → эволюционный сигнал
- **Harness Handbook**: trace-to-code mapping (failure pattern → harness component → source)
- **Cross-framework search**: механизмы из OpenHands/SWE-agent/Terminus/mini-SWE-agent
- **Behavioral checks + repeated evaluation** = наш Auditor gate

### 4. **DarwinX = Population-Based Selection**
- **Preserve-and-extend contract**: no regression + adds coverage
- **Archive**: сохраняет alternative lineages для recombination
- **avg@k promotion**: stricter than single-run
- **Cross-benchmark transfer**: TB2.1 harness → SWE-bench Verified zero-shot

### 5. **AutoSwarm = Agent Contracts + Shared State**
- **Responsibility boundaries + acceptance conditions** = explicit agent contracts
- **Shared execution state**: progress, dependencies, blockers, next actions
- **DAG + supervisory relationships** = Coder→Auditor→Professor hierarchy
- **Gatekeeping**: downstream waits for upstream acceptance

### 6. **Continual Harness = Reset-Free Cron**
- **Уже есть по форме** (наш крон бесконечен), но **нет по содержанию**
- **Refiner every F steps**: CRUD edits to prompt, sub-agents, skills, memory
- **Capability floor**: weak models (780M) могут не benefit от сложных harness
- **Joint harness + model training**: same trajectory → harness edit → GRPO/BAR
