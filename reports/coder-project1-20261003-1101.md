## Пункт 12 (добавлен в ходе слота) — диагностика порчи исходников

### Находка на входе слота — проект был мёртвым

`p1_memory/chronicle.py` лежал на диске повреждённым:
- **NUL-байт** в docstring (смещение 530) → Python не импортирует файл вообще;
- **обрыв текста** на ~560 байт (3778 Б в git против 3219 Б на диске);
- **посторонняя строка** `п.Threading is disabled for this response.` —
  хвост LLM-конвейера, попавший в исходник вместо текста.

Симптом: `unittest` падал с `SyntaxError: source code string cannot contain null bytes`,
и **ни один из 61 теста не запускался** — ни один, а не «часть». Проект
выглядел рабочим (файлы на месте, git чист по коду) и при этом был полностью мёртв.

Порча содержательных правок не несла: обе строки, отсутствующие в HEAD,
являлись артефактами обрыва. Восстановлено через `git checkout --`, испорченный
экземпляр сохранён для разбора (`~/.hermes/cache/scratch/chronicle.py.corrupt`).

### Что сделано (закрывает класс дефекта, а не симптом)

`p1_memory/doctor.py` + команда `python3 -m p1_memory doctor`:
- правила: null-байты, невалидный UTF-8, служебные хвосты конвейера,
  синтаксис (ast), реальная компиляция (`compile()`);
- `is_blocking()` отделяет порчу от предупреждений;
- exit 1 при порче, `--json`, `--all`.

**Три решения по границам правил, важные для Аудитора:**

1. **«Обрыв» (нет завершающего `\n`) — предупреждение, не порча.** Инструмент
   записи в этой среде штатно срезает последний перевод строки у всех файлов:
   первая версия doctor давала 8 ложных срабатываний на целом проекте. Блокирующим
   это правило сделало бы doctor бесполезным. Настоящий обрыв ловится правилом
   «синтаксис» — обрезанный файл не разбирается.
2. **Служебная фраза распознаётся только если строка целиком из мусора**
   (префикс 1–3 символа). Первая версия ловила **сама себя** — фраза была
   в её же docstring. Покрыто тестом `test_mention_of_junk_phrase_is_not_corruption`.
3. **В текстовом выводе по умолчанию только блокирующие находки**, иначе 8
   предупреждений топят сигнал порчи. Полный список — `--json` / `--all`.
