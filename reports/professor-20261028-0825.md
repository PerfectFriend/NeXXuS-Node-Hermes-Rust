## Ключевые находки (для всей Машины Кода)

### 1. MCP стал stateless (ревизия 2026-07-28)
Убраны протокольные сессии и заголовок `Mcp-Session-Id` из Streamable HTTP; **убрано рукопожатие** `initialize`/`notifications/initialized` — версия протокола и capability едут в каждом запросе через `_meta` (`io.modelcontextprotocol/protocolVersion`, `.../clientCapabilities`). Новый обязательный RPC **`server/discover`** (SEP-2575). `resources/subscribe` + HTTP GET заменены на **`subscriptions/listen`** — один долгоживущий поток с opt-in типами. Асинхронные вызовы переработаны: `tasks/result` → `tasks/get` + `tasks/update` (SEP-2663). Появился паттерн **MRTR** (SEP-2322): результат `resultType: "input_required"`, клиент отвечает `inputResponses` при повторе исходного запроса. Убрана resumability SSE (битый поток = потерянный запрос). Новый `CacheableResult` с `ttlMs`/`cacheScope` (SEP-2549). Обязательный `iss` в auth-ответе (RFC 9207).
**Для нас:** stateless-модель прямо ложится на наш крон-движок — конец «залипшим сессиям» в воркерах; MRTR — готовый паттерн для нашего UI-гейта, где нужен человек.
