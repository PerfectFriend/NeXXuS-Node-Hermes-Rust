## Что извлечено (суть, не пересказ)

**Lemonade SDK** — Apache-2.0, C++, ⭐5999, push 2026-10-26. Пять API-семейств: OpenAI / Ollama / Anthropic / **MCP Gateway (POST /mcp)** / llama.cpp-специфичное. Сервер сам отдаёт свою спецификацию (`GET /v1/docs`) — doc-дрифт закрыт по построению. CLI: `run / launch / pull / list / alias / backends`; `alias` = active-standby failover между моделями. Бэкенды: llamacpp × {system, metal, cuda, **vulkan**, **rocm**, cpu}; форматы GGUF/FLM/ONNX (FLM — для XDNA2 NPU). Установка на Linux: Ubuntu PPA, Debian, Arch, Fedora, Snap, Docker. Для нас: единая точка входа для роя (OpenAI+Anthropic+Ollama+MCP в одном процессе), локальный MCP вместо облачного, hot-swap моделей без паузы.

**SAGE Gate** — наивный гейт «прими правку, если вырос агрегатный score» ломается дважды: (1) пропускает перманентные регрессии, скрытые средним; (2) подвержен проклятию оптимизатора (лучший score на конечной шумной выборке смещён вверх). Решение: **парное сравнение по каждому item на одних и тех же валидационных items** + **односторонний парный тест** + **воздержание (abstain)** при незначимости. Регрессии: 36.5%→0% (LiveMath), 42.8%→0% (OfficeQA); финальный score — высший во всех 20 настройках (LiveMath 34.15→48.78). Прямая замена нашим flaky gates; реализуется ~20 строками арифметики.

**Code as Agent Harness** (arXiv 2605.18747) — код как операционная подложка агента: три слоя (harness interface → harness mechanisms: planning/memory/tool-use/feedback-driven control → scaling на мультиагент). Шесть открытых вызовов, из них наши: *regression-free harness improvement* (её закрывает SAGE), *согласованное общее состояние между агентами* (наша гонка записи в journal.md), *evaluation beyond final task success*, *human oversight*.

**Magnitude** — ⭐**7340** (в Учебнике было 6106 — исправлено), Apache-2.0, Rust, создан 2026-06-12, 1567 коммитов, push 2026-10-26. Профилирует машину и тюнит ядра под неё; README заявляет «2x faster than Ollama» и **one-click интеграции с Pi, OpenCode, Hermes, Codex**. Оговорка: цифра «2x» — заявление самого проекта, независимого воспроизведения нет. Риски для нас: инструмент пишет harness config (может задеть `~/.hermes/config.yaml` — только через dry-run), требует `rocminfo` для AMD-пути, добавляет ещё один рантайм на машину с 15.4 ГБ RAM.

**COGNIT-Guard** (arXiv **2609.33671**, Hao Chen) — каскад «дешёвый CPU-гейткипер + дорогая эскалация на Laya-322M (NPU)», маршрутизация как cost-sensitive risk minimization: калибровка + порог θ*deploy + асимметричный штраф за FP + SLO по задержке. DUCS-Bench (N=607, чистый unseen): accuracy 98.85%, benign FPR 0.42%, ECE 1.12%, Brier 0.0104; Ascend 910C — 21.77 мс на NPU, 41.63 мс в каскаде. Alignment tax: OOD 60.33%→56.81%, experience replay возвращает 64.10–65.05%. Оговорка: всё self-reported, веса/код Laya-322M не указаны.
