## Key Insights

### Accept-Markdown — Serve Markdown to AI Agents with Accept Headers
- HN Show (120★/11h): подход «отдавать самай сайт как Markdown по `Accept` заголовку» вместо отдельного API — агенты читают человеческий контент напрямую.
- Паттерн: тот же URL, но сервер смотрит `Accept: text/markdown` (или `application/json` для agent) и отдаёт очищенный markdown, а браузеру — HTML.
- Значимо для sovereign/self-host стека владельца: сайты магазина/доков ParanoidX можно делать «agent-readable» без отдельного API.

### ai-job-search — AI Job Application Framework on Claude Code
- Агентный фреймворк: оценивает вакансии, подгоняет CV, пишет сопроводительные, готовит к интервью — целиком локально.
- Показательный паттерн «агент как персональный офисный рабочий» поверх Claude Code + fork-it-and-own-it.

### OzBrain — Shared Brain for Knowledge Between Agents and Team
- Общий слой знаний, доступный и агентам, и людям — единый источник контекста для роя.
- Перекликается с OpenViking (agent context DB) и ai-memory из §14 — централизованная память вместо разъезжающейся.

### forklane.ai — Multiplayer Coding Environment for Dev Teams and Agents
- Совместное (real-time) окружение, где параллельно работают и люди, и агенты — гибридная разработка.
- Тренд: агенты становятся полноправными участниками командного рабочего процесса, а не фоновыми утилитами.
