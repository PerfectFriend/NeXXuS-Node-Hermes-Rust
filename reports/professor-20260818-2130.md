## Topics Studied: RunNburn, Fronde, DeepSpec/DSpark

### RunNburn
- **What it is**: Memory-aware GGUF inference runtime for hardware with tight RAM/VRAM constraints.
- **Key Insights**:
  - Keeps GGUF weights file-backed (mmap'd) without expanding into oversized resident copies.
  - Model-aware execution paths for dense attention, GatedDeltaNet, Mamba-style recurrence, sparse MoE.
  - Supports native quantized kernels (Q2_K through Q6_K, Q4_0, Q8_0) across x86, ARM NEON, CUDA, Metal.
  - Single product contract: CLI, Rust API, Android C ABI, OpenAI-compatible server.
  - Enables running large MoE models (e.g., Tencent Hy3 295B/21B active, 97.8 GiB Q2_K GGUF) on 64GB RAM desktop with consumer GPU.
- **Applied To**: Local LLM inference setup for Hermes Agent.
- **Next Steps**: Test runNburn with Hermes' llamacpp provider for dynamic model switching.

### Fronde
- **What it is**: Adaptive speculative decoding on a ~€300 GPU (RTX 5060) using a small draft model.
- **Key Insights**:
  - Draft model (0.6B) proposes tokens; target model verifies, reducing expensive target model passes.
  - Significant speedup for structured content (code, math, JSON); less for prose.
  - On Linux, draft overhead becomes negligible (~0.99×).
  - For editing tasks (high copy fraction), speculation yields up to 9.27× speedup.
  - ngram-simple as safe floor with no regression and up to 9.27× on edits.
  - FRONDE-Router dynamically selects between draft model (aggressive) and ngram-simple (safe) based on 48-token probe and EMA collapse detector.
  - Invariants: ≥ baseline on all content types, ≥ 90% of static champion on code/math/JSON.
- **Applied To**: LLM inference optimization for Hermes Agent (local Llama/Variant models).
- **Next Steps**: Examine FRONDE-Router implementation; test with Hermes' llamacpp provider.

### DeepSpec/DSpark
- **What it is**: Full-stack codebase for training and evaluating draft models for speculative decoding.
- **Key Insights**:
  - Includes three draft model algorithms: DSpark (Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation), DFlash, Eagle3.
  - Workflow: data preparation (download prompts, regenerate target answers, build target cache), training, evaluation.
  - Data preparation requires an inference engine for the target model; target cache can be very large (~38 TB for Qwen3-4B).
  - Training uses one worker per visible GPU; configurations under `config/`.
  - Evaluation runs over benchmarks (gsm8k, math500, aime25, humaneval, mbpp, livecodebench, mt-bench, alpaca, arena-hard-v2).
  - Released checkpoints on Hugging Face (e.g., `deepseek-ai/dspark_qwen3_4b_block7`).
  - Paper: "DSpark: Confidence-Scheduled Speculative Decoding with Semi-Autoregressive Generation" (arXiv:2607.05147).
  - MIT Licensed.
- **Applied To**: LLM inference optimization for Hermes Agent (speculative decoding pipelines).
- **Next Steps**: Examine DSpark algorithm details; test DeepSpec-trained draft models with Hermes' llamacpp provider.
