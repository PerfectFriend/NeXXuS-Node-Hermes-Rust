## Главные находки

**1. Атрибуционная ошибка в Учебнике (исправлена, это главный результат слота).**
Тема была записана как «MCP SDK OAuth CVSS 7.5: злой сервер перехватывает client secret, auth code, PKCE через провокацию 404 на discovery», со ссылкой на несуществующий `GHSA-xxxx`. Живой `GET /repos/modelcontextprotocol/python-sdk/security-advisories` вернул **12 advisory**, и картина другая:
- **CVSS 7.5 — это CVE-2026-59951** (GHSA-84m7-p3x7-pcfv): неограниченное накопление сессий в StreamableHTTP (не OAuth). Затронуты `mcp 1.8.0–1.29.1` и `2.0.0–2.1.1`, фиксы **1.30.0 / 2.2.0**.
- **OAuth-дефект — это CVE-2026-115563** (GHSA-qx49-fqc8-xw99, severity **high**, без опубликованного CVSS): «OAuth client could send credentials to an authorization server **chosen by the MCP server**». Формулировка «перехват client secret через провокацию 404» **не подтверждается первоисточником**.
- Ещё в каталоге: bearer-токены для чужого resource server (medium), тело запроса без лимита (CVE-2026-109527, high), кросс-оригинальные редиректы с кастомными заголовками (medium), `$ref`-URL, выбранные сервером (medium), DNS-rebinding protection выключен по умолчанию (CVE-2025-66416, high) и ещё 6.
- **Наша экспозиция нулевая — проверено тремя независимыми способами:** `grep -c '^mcp_servers' ~/.hermes/config.yaml` → 0; `import mcp` → ModuleNotFoundError; FastMCP/streamable_http_app у нас не поднимается. То есть обе ветки (session accumulation, unbounded body) неприменимы.

**2. Наша гонка записи имеет готовое инженерное решение (Unreal Agent).**
Живой README + GitHub API: 2213★, MIT, Go, push 2026-10-23. Модель не маркетинговая, а формальная: **Input с глобально уникальным ID от вызывающего** (стабилен при повторной доставке) → **сессионный Inbox в памяти** для дедупа → **append-only Session с форками** → **Tool translator без I/O** → **Operation** как сериализуемое описание работы + **Operation manager** как actor-рантайм для долговечных операций. Три наших дефекта закрываются по одному механизму каждый: повторный вход, гонка записи в общем файле, потеря частичной работы. Отдельно: **context builder возвращает запись обо всём, что усечено** — у нас отчёт не содержит «прочитал строки N–M, остальное не просмотрено».
