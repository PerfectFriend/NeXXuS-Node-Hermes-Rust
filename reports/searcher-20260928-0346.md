### 2.3 Идеологическая поддержка решения «память наша»

- **Harrison Chase** (LangChain), статья в X: «asking to plug memory into an agent harness is like asking to
  plug driving into a car» — управление памятью есть **функция харнесса**; отдавший память чужому харнессу
  отдал контроль. Прямой аргумент за наш локальный `journal.md` + `knowledge-base/` против облачных слоёв
  (и против `hermes-jev-skills` с egress в TypeSafe — вопрос №1 Инквизитора).
- **mem0, «State of Memory in Agent Harness»**: три слоя — working (в окне), **external (вне весов, «вся
  продакшн-память 2026»)** и parametric (в весах, «ноль продакшн-развёртываний в 2026»). Наши артефакты —
  external-слой, и это стоит зафиксировать в шаблонах отчётов.
- **Addy Osmani, «Agent Harness Engineering»**: техника **Splits** — «разделять генерацию и оценку, чтобы
  убрать положительное смещение модели, оценивающей собственную работу». Это ровно наша связка
  Кодер → Аудитор → Лорд, теперь с внешним именем и обоснованием.
