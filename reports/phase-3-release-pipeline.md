**Шаги конвейера:**
1. **Вердикт Владыки** — проверяет `journal.md` на ВЕРДИКТ: ГОРЯЧИЙ для проекта
2. **Чек-лист релиза** — код холодный (нет [СР]), нет uncommitted-изменений, `check_roster.py` rc=0, ассеты закоммичены, ui_gate пройден

4. **Тегирование** — создаёт аннотированный тег `{proj}-v{version}` и пушит в origin
5. **APK экспорт** — копирует `*.apk` из проекта в `~/apkexport/` с именем `{proj}-v{version}-{имя}.apk`
6. **Отчёт** — пишет `reports/release-{proj}-v{version}-{ts}.md`
7. **Доставка** — отправляет отчёт в топик 252 через Telegram Bot API
