## Ключевые инсайты для Машины Кода

### 1. AMD 780M — два путя, оба нужны
- **Workaround (HSA_OVERRIDE_GFX_VERSION=11.0.2)** = production RAG path, ставим прямо сейчас
- **Native build (ollama-for-amd + Fedora gfx1103 kernels)** = heavy prefill/batch path, для задач где нужен настоящий gfx1103 throughput
- Kernel 7.0.0-15+ (HWE) + `amdgpu.gttsize=24576` — обязательные предреквизиты

### 2. ESP-Mosaico = новый класс UI-гейтов для hardware-агентов
- ESP-Claw как встроенный агент (Chat Coding) + Vibe Coding (desktop→hardware loop)
- ESP-GSP: JSON UI + build-time validation + PC simulation → паттерн для наших UI-гейтов
- AG-UI-совместимый интерфейс, $59 devkit — доступно для масштабного тестирования

### 3. ultraswarm = эталон оркестрации через worktrees
- Изолированные Git worktrees на воркера + транзакционный мерж
- Capability-based routing + SQLite state + append-only events
- SmallHarness = Rust multi-backend worker с нативным MCP — прямой кандидат для нашего локального worker'а

### 4. JIT-Agent = парадигма AOT → JIT harnesses
- Харнесс генерируется под задачу (4 модуля + HarnessFactory), не заранее
- 3 стадии: Synthesis → Repair (bounded trajectories) → Evo-GDPO (reward/latency/cost normalization)
- Harness Intelligence = trainable, transferable, compounding dimension orthogonal to model scaling

### 5. DeepSeek-for-VS = эталон 5-агентной IDE-архитектуры
- Ask/Explore/Plan/Edit/Build с Handoff протоколом
- Runtime read-only enforcement (tools-level, не prompt-level) — паттерн для наших гейтов
- Plan as artifact (файл + steps pending panel), structured test results, patch healing

### 6. AOrchestra = динамическое создание под-агентов через 4-tuple
- (Instruction, Context, Tools, Model) = unified interface для спавна специализированных исполнителей
- Orchestrator не выполняет задачи, только создаёт правильных исполнителей
- Context curation + tool/model selection per subtask — наш крон должен это уметь
