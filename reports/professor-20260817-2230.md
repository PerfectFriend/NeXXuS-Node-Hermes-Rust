## Key Findings

### Setup Paths for AMD 780M
1. **Native ROCm (Recommended)**: johnsonfarmsus one-command setup, builds ollama-for-amd from source with Tensile kernels
2. **Ollama-for-AMD Installer**: ByronLeeeee's installer, easier click-to-update approach
3. **llama.cpp Vulkan Fallback**: Works on 780M when ROCm fails, using Vulkan backend
4. **PyTorch ROCm**: For training/fine-tuning with ROCm 6.3 or newer

### Performance at Q4_K_M Quantization
- Qwen3-8B: ~15-25 tok/s — good balance
- DeepSeek-Coder-6.7B: ~20-30 tok/s — code optimized
- Nemotron-3.5: ~10-15 tok/s — larger model
- Llama-3.2-3B: ~30-45 tok/s — fast, small

### Known Issues & Workarounds
- ROCm inconsistent on iGPU → Try Vulkan backend first
- gfx1103 kernels missing → Use Fedora 43 Tensile kernels
- Ollama ROCm not detecting GPU → Set `HSA_OVERRIDE_GFX_VERSION=11.0.3`
- OOM on 780M shared memory → Use smaller quant, limit context
