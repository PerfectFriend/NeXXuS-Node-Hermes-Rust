### Ollama ROCm gfx1103 Build Instructions

```bash
# 1. Clone & patch Ollama
git clone https://github.com/ollama/ollama && cd ollama
# Apply 3 patches to ml/device.go (from johnsonfarmsus/ollama-rocm-gfx1103-ubuntu)
# 1. Add gfx1103 to AMD GPU list
# 2. Fix VRAM detection for iGPU (GTT)
# 3. Disable flash attention by default

# 2. Build with ROCm target
AMDGPU_TARGETS=gfx1103 go build -tags rocm -o ollama-for-amd .

# 3. Extract Fedora 44 rocblas-7.1.1 gfx1103 Tensile kernels
# rpm2cpio rocblas-7.1.1-1.fc44.x86_64.rpm | cpio -idmv
# cp usr/lib64/rocblas/*.so /opt/rocm/lib/

# 4. Systemd drop-in (/etc/systemd/system/ollama.service.d/rocm.conf)
Environment=OLLAMA_FLASH_ATTENTION=0
Environment=CONTEXT_LENGTH=16384
Environment=NUM_BATCH=256
Environment=KEEP_ALIVE=86400
Environment=HSA_OVERRIDE_GFX_VERSION=11.0.2
Environment=AMDGPU_TARGETS=gfx1103
# GRUB: amdgpu.gttsize=24576 (24 GB GTT)
```
