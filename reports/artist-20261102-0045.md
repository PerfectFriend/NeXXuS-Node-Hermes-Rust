## Design Philosophy: Neon Mosaic

The **Neon Mosaic** movement synthesizes three visual languages without hierarchy:

1. **Cyberpunk** — the skeletal grid: circuit traces, holographic interfaces, silicon logic
2. **Van Gogh** — the emotional dissolution: impasto swirls, energy made visible, pigment as memory
3. **Gaudi** — the organic mediation: trencadis mosaics, living architecture, structure that breathes

Each card implements:
- **Three-color chord** per arcana (dominant, subdominant, accent) drawn from three frequency bands
- **Three rhythmic systems** in phase interference: 8px cyberpunk grid, Fibonacci spiral armature, 13px Gaudi tessellation
- **Dynamic asymmetry** on golden-ratio vertical divisions
- **Three-level visual hierarchy**: silhouette → mosaic field → micro-typography
- **Minimal text**: Roman+binary number, trilingual name (EN/RU/Glagolitic), elemental sigil, Hebrew letter, Path number
- **Subtle reference**: Hermetic "As above, so below" encoded as recursive fractal traversal across all 22 cards

## Technical Specifications

- **Format:** SVG 1.1, valid XML, self-contained (embedded gradients, patterns, filters)
- **Canvas:** 816×1188px (744×1116 content + 36px bleed)
- **Color space:** sRGB, hex notation
- **Typography:** System fonts (Georgia serif, monospace, sans-serif) — no external dependencies
- **Filters:** Custom brushstroke (feTurbulence + feDisplacementMap), neon glow (feGaussianBlur + feMerge)
- **Patterns:** Mosaic (trencadis), circuit trace — both tileable
- **Print-ready:** CMYK-safe palette, bleed included, vector throughout
