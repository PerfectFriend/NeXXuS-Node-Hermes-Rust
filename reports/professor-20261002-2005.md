### 3.1 jev-judge-mcp — laya 1.6537
`knowledge-base/Pass18-Judge-Gate-Jev-MCP-Selective-Accuracy-2026.md`

- README прочитан целиком. **Правка к дайджесту: инструментов 14, а не 11.** Среди них
  `jev_file_judge` — судить файл не читая: сервер берёт путь как state, байты **никогда не
  входят в контекст агента**. Для наших гейтов это образец формы.
- Наш вопрос дословно: `jev_gate` — «соответствует ли отчёт агента тому, что сделано»,
  возвращает одно решение ship по патчу и каждому completion claim.
- **Замер модели:** JevBench public 89/92; `selective_accuracy_auto` **1.0**, `auto_coverage` 0.935,
  `micro_f1` 0.9727. То есть **86 из 86 автопринятых верны**, все 3 промаха ушли в review.
  Это bound-подход в действии, а не «модель ответила верно».
- **Замер агента — и он противоположный.** Два независимых исследования авторов:
  23.09 — решения те же, но медленнее; 27.09 — **5/9 с Jev против 9/9 без**, медиана
  38.9 с против 22.6 с, **140 032 против 36 328 токенов на задачу**. Дайджест привёл только первое
  и написал «результат не изменился». Полный текст даёт второе, где результат **ухудшился**.
- Стоимость: $0.025 за 1000 решений, медиана 464.6 мс.
- Ограничения объявлены авторами: `rerank` ≤250, `classify` ≤64 items и ≤250 классов,
  `decide` 2–6 вариантов, `score` 2–10 уровней, `extract` ≤50 000 единиц.

### 3.2 Von + /v1/systemone — laya 1.5719 / 1.4885
`knowledge-base/Pass18-SystemOne-Portal-Von-Measured-Threshold-2026.md`

- **Блог llama.cpp прочитан целиком** (PR #29818, 02.10.2026). `POST /v1/systemone`,
  три типа вопросов, вероятность по каждому варианту за один forward pass, совместимость
  с TypeSafe — «клиентам достаточно сменить base URL».
- **Про Laya — две разные модели, и это надо сказать вслух.** Табличная — `ggml-org/Laya-GGUF`,
  421M ModernBERT-large, **English**, 512 контекст. Наша — `models/laya-multilingual/`, mmBERT,
  100+ языков, 1024 контекст, своя обвязка. Английская версия теперь на мировом рантайме,
  многоязычная — нет.
- **Таблица моделей** (медиана на RTX PRO 6000): Julia-1 144M/3мс · **Laya 421M/5мс** ·
  Kev-4B 12мс · lev 36мс · OpenJev 27B/43мс, единственная с картинками (CC BY-NC).
- **Von README — главная находка прохода.** Порог **0.80 измерен**, а не выбран:
  `benchmarks/sweep_threshold.py`, held-out jabr v2 + пробы кодинг-агента, веса Von 1.2.
  Choice ≥0.80 → 25% выборки при **92.4%** (нижняя граница 90%: 89.4%, n=702), остальные 75% на 59%.
  Noul → 16% при 83%, гейт посажен на `noul_raw`, **потому что итоговый лежит в фиксированной
  полосе и не несёт сигнала**. Низший cutoff с 90% kept-accuracy при 90% уверенности — **0.82**.
  Вне домена kept-accuracy плоский при любом cutoff — авторы пишут это прямым текстом.
- **`von calibrate labels.jsonl`** — рефёт карты уверенности на своих метках, замёрзшие веса,
  CPU, минуты; печатает NLL/ECE для raw/shipped/scalar/map. **Это готовый код для проверки
  вопроса Инквизитору №1 прохода 11** (`c·e ≤ β`) — bound-правило, выраженное и работающее.
  Плюс: temperature никогда не меняет ответ, только заявленную уверенность.
- **Von — только английский.** Другие языки получают token matching с уверенностью, которой
  он не заслужил. Наша многоязычная Laya здесь честнее.
- Два правила экономии: `judge` без `criteria` — слабейший путь, побеждают поверхностные признаки;
  `--on-overflow refuse` → 422 со ссылкой на окно вместо тихой обрезки.

## 4. Сквозные выводы прохода

1. **Порог — не точка на шкале, а измеренная величина.** Теперь **четыре** независимые работы
   об этом (было три): Jevstiller, AIM-Decision, Von/llama.cpp, jev-judge-mcp. Ответ на вопрос
   Инквизитору №1 прохода 11 можно теперь дать измерением, а не мнением.
2. **Калибровочная полоса может убить сигнал гейта.** Прямое предупреждение о нашем риске:
   если выход зажат в полосу, гейт по нему бессмыслен.
3. **Keyword-базовая линия — самая дешёвая недостающая метрика.** Мы не сравнивали свой гейт
   с keyword-базисом на собственных находках. Стоит один день работы.
4. **Принудительный вызов судьи ухудшает результат** (5/9 против 9/9, ×3.9 токенов). Наша гейт-приёмка
   не должна быть «всегда звать laya».
5. **Мы не считаем selective accuracy.** Есть только point estimate; «из автопринятых ни одно
   не неверно» — метрики нет.
6. **Совместимость — контракт на диапазон, а не на формат:** 3 модели из 4 не смогли начать 24
   задачи из 50 (сервисы принимают 2–26 вариантов, на странице больше 26 контролов).
