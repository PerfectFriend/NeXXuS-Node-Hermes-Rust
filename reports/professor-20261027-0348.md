   прокси может enforce'ить политику, **не разбирая JSON**. Resumability SSE снята →
   неидемпотентные tool-хендлеры обязаны дедуплицировать сами. Длинные задачи — через
   tasks-расширение (`tasks/get`). Следствие: категория «session-aware routing gateway»
   (Microsoft MCP Gateway) обесценена.

   год придётся держать обе за одним gateway. `mcp-remote` с критическим RCE 2025 всё ещё
   качают 716k/нед.
3. **Токены — главная валюта агента.** 5 типовых MCP-серверов = ~55 000 токенов определений
   до первого слова; точность падает после 30–50 инструментов. Фиксы: отложенная загрузка
   через search-tool (77 000 → 8 700, точность 49 → 74 %), code execution with MCP
   (150 000 → 2 000), `ttlMs`-кэш списка инструментов.
4. **AG-UI — правильный слой для UI-гейтов.** Interrupts (approve/edit/retry без потери
   состояния) и agent steering уже в протоколе. Но: не плодить render-tools — после ~15
   компонентов (~400 токенов каждый) надо переходить на A2UI с одним schema-tool.
5. **Cortex даёт три переносимых паттерна:** auto-tuned concurrency по модели (для локального
   Ollama = 1 параллельный вызов), signal-gated обучение с подтверждением (новые паттерны —
   только как delta-предложения), quality floor с автоматической ремедиацией ответа.
6. **okf-agent-memory — самый применимый к нашей памяти:** push/pull разведение (кодекс ~100–150
