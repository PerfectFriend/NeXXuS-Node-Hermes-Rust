fix(i18n, entrance): honest setLocale, dead branch removed, corrupt sequence guard, cancellable hint timer

Cycle 5 (2026-10-02). Probes: reports/tmp_probe_cycle5.mjs / _cycle5b.mjs.

src/i18n.ts
1. [СР] setLocale() silently swallowed an unsupported locale — setLocale('fr')
   and setLocale('RU') left the app on the previous language with no signal
   at all, so a caller could not tell "switched" from "failed". It now
   returns boolean.
2. [Н] detectSystemLocale() carried a dead loop (`for key: lang.startsWith(key)`)
   meant for zh-CN style locales. It was unreachable for ANY navigator.language:
   an exhaustive sweep of 184 ISO-639-1 codes found zero inputs where the loop
   changed the answer, because the preceding split('-')[0] check already covers
   both 'xx' and 'xx-YY'. Removed, with the reason recorded in place.

src/hooks/useHiddenEntrance.ts
3. [СР] getStoredSequence() returned raw JSON.parse, so a corrupt
   localStorage value (object, string, number) made the first tap throw
   "stored.map is not a function" — the secret entrance threw instead of
   simply not firing. Array-checked and junk-filtered.
4. [Н] With no stored sequence the target is empty, and .slice(-0) === .slice(0)
   made the sliding window meaningless, so the entrance's behaviour depended on
   an empty string. An empty target now never matches.
5. [Н] The 3-second hint timer was never cancelled: reset() cleared showHint but
   the pending timer still fired setState afterwards. The handle is tracked,
   cleared before re-arming, and a cleanup effect cancels it on unmount.
