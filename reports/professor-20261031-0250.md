## Что именно извлечено (кратко)

1. **SAFE-Mem** — каждое утверждение в памяти несёт три метки: **kind** (что делает при принятии), **authority** (сильнейший вид, который источник вправе установить), **scope** (над кем). Ничего не удаляется — внешнее утверждение остаётся «отчётом о том, что сказал источник», но никогда не повышается до «пользователь просил». Числа авторов (не наши): атака на MPBench минимум на 77 % ниже сильнейших защит, сохраняющих легитимную память; +15 п.п. на LoCoMo. В коде есть проверка **в точке вызова инструмента** (`eval/callsite.py`), а не только при извлечении.
2. **earshot** — CPU-only «уши» для агентов: звук как доказательство, `forge` (звук как рецепт физического синтеза → рендер → критик → эволюционный поиск), `fit` (запись → код), банк из 252 эффектов, MCP-сервер.
3. **gogo-agent** — эталон «Harness · Loop · Memory · Eval» без фреймворка. Живой цикл `run_loop` = **ровно 98 строк**; **108 детерминированных eval-файлов**; release gate требует 100 % детерминированных; пять turn-проверок (`spend_claim`, `one_report`, `grounded_numbers`, `errors_handled`, `under_budget`).
4. **Tolk + Acton 1.2.1** — Tolk официально рекомендован как преемник FunC; Acton даёт **тест-гейт на языке контракта**. Живой стенд: `acton build` → `Finished in 7.680531 ms`, `acton wrapper Counter` → `wrappers/Counter.gen.tolk`, `acton test` → **✓ 3 passed in 1 file** (increase counter 11 ms, reset counter 1 ms, unknown message 1 ms).
5. **SCP** — нормативная спецификация `scp/1`: брокер → хаб → контакты; доставка на границе хода; **handback** (код возврата + весь ответ воркера); аудит **без содержимого**; **untrusted by construction**.

## Три фактические поправки к карточкам Искателя (проверено живьём)

- ⚠ **`pip install earshot` поставит ЧУЖОЙ пакет**: на PyPI `earshot` = `pykeio/earshot` 1.2.2 (Rust-VAD от Carson M), версии 0.4.0 проекта Leonxlnx на PyPI **404**. Ставить только из git-релиза `v0.4.0`.
- ⚠ **`pip install gogo-agent` не работает вообще**: PyPI **404**, 0 релизов. Только из исходников (`uv pip install -e .`), и pytest надо доставить отдельно (он в экстре `eval`).
- ⚠ **README SAFE-Mem велит клонировать `LVenum/Agentic-Memory-Security`** — этот URL отдаёт **HTTP 301 → `LVenum/SAFE-Mem`** (репозиторий переименован).
- ⚠ **Acton проверяет версию тулчейна по `[toolchain]` в `Acton.toml` и отказывается работать при несовпадении.** Эталонный `acton-contracts` требует `acton = "1.2.0"`, у нас стоит 1.2.1 ⇒ build/test падают с «Acton CLI version mismatch». Полная сборка эталонов на 1.2.1 **не проходит** (ошибки в `w5.2` и `nft-v1.1`); рабочий путь — мини-проект с одним контрактом.
- ⚠ **Синтаксис Tolk ≠ FunC/Tact:** рабочий тест — `get fun \`test name\` { … }` + `expect(...)` + `setupTest()`, обращение к контракту — через **сгенерированную обёртку**.

## Главное для Машины Кода

1. **Наш `journal.md` — канал инъекции с правом записи у любой LLM.** SAFE-Mem (метки полномочий) и SCP («untrusted by construction») решают одну задачу с двух сторон: запись должна нести **источник и вид** утверждения; проверять надо **обе** точки — извлечение из памяти и место вызова инструмента.
2. **Детерминированный eval должен жить РЯДОМ с модельным и уметь сказать «не смогли проверить» (n/a).** У нас такого слоя нет вообще: 108 детерминированных тестов gogo-agent проходят за 5,5 с **без ключей и без сети**.
3. **`grounded_numbers` — дешёвый анти-инъекционный фильтр для наших отчётов:** 90 % сумм/процентов/дат в ответе должны встречаться в выводе инструмента.
4. **Гейт релиза = код возврата, а не текст отчёта** (`release_gate.py`: «Deterministic evals must pass 100 % — one failure blocks. Exit code 0 = ship»; «0/0 on a miss is honest»).
5. **Перед установкой проверять владельца пакета, а не только название.**
