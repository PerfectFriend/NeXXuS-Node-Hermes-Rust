## Что дала каждая тема (коротко)

1. **routeVSCODE** — запись Искателя была выдумкой без источника («VS Code Extension/Route
   Optimization»). Первоисточник: `yudaprasetya007/routeVSCODE` (nashsu — форк). Это локальный прокси
   на :20129, который инжектит имя модели и гонит SSE в 9Router (:20128) → 40+ провайдеров. В VS Code
   модель выбирают один раз, дальше переключение кликом без reload.
   **Польза:** паттерн «имя цели отделено от модели в конфиге + подмена цели на лету» — ровно то, что
   нужно нашим роягентам. Продукт не ставил и не рекомендую: лицензия/качество не проверены,
   глобальный npm `9router` требует аудита.

2. **Lemonade 11** — локальный сервер (Apache-2.0, спонсор AMD) на llama.cpp/whisper.cpp/
   stable-diffusion.cpp/kokoros/ORT-GenAI, отдаёт OpenAI + Anthropic + Ollama API на
   `http://localhost:13305/api/v1`.
   **Польза:** (а) единая точка входа для роя — любой OpenAI-совместимый клиент цепляется без правок;
   (б) `lemonade alias` = готовая схема энергонезависимого имени цели + active-standby failover;
   (в) мультимодальность на одном порту (LLM + SDXL + kokoro TTS + Whisper).
   **Правка факта:** HRX (`llamacpp-hrx`, experimental) заявлен для gfx1100 (RX 7900) и gfx1151
   (Strix Halo), Linux. Наш 7800 XT = **gfx1102** — HRX официально НЕ заявлен. Прежняя запись обещала
   «замену Vulkan на HRX у нас» — это гипотеза, требующая бенчмарка, а не факт.

3. **EvoUndo** (arxiv 2608.28363) — кандидат-мутация = 4-кортеж `ξ = (m, w, u, Ce)`; проверка отката
   round trip'ом на разработческих и **скрытых** состояниях; сравнение по типизированной наблюдательной
   эквивалентности, а не побайтово; допуск при 95% Wilson lower bound ≥ 0.85; при ремонте прямая
   мутация заморожена. Числа: обычные repair-стратегии вылечили 0/197 естественных отказов, oracle L0 —
   48/197, расширенный L1 — 191/197. **Польза:** два узких места (grounding «не знаю, где состояние»
   vs expressivity «язык не может выразить откат») мы раньше лечили одним «перепиши промпт» — это
   прямая ошибка нашей практики эволюции.
