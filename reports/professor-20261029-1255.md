### 4. vibeweaver — laya 1.4017
`Vibeweaver-Graph-Gated-Skill-2026.md` · MIT, ★6, push 29.10.2026, 9 858 КБ, README 68 641 Б прочитан.
Граф-автомат из 4 панелей: **узел = стадия с обязательными артефактами** («готово» = артефакт

`vibeweaver-audit` **защёлкивает RED в рамках сессии** (снимается сменой сессии/TTL/следующей
задачей; повторный аудит с той же сигнатурой сбора не воскрешает). Стандарты: test-first

убьёт чужой сервис). loop-guard ловит **intent-action decoupling**: модель называет вызов, а выдаёт
no-op `echo "…"` — 4 подряд различных no-op ⇒ прерывание; честно объявленные пробелы: `sleep`/`ls`
и колебание echo/read. **Для нас:** `cap=5`/`stall=3×` — единый контракт цикла; **`GATE-BLOCKED`
вместо просьбы** — прямое усиление нашего гейта; сессионная защёлка со снятием вместо вечной
блокировки. ⚠ Не устанавливал; плагины — API **opencode**, порта под Hermes нет (есть порт под DSH).

4. **Хранить квитанции, а не утверждения** (adaptive-agent-harness): «запрошено vs эффективно»,
   номер ретрая, третье состояние `indeterminate`.
5. **Измерять перенос, а не только прирост** (SEAGym + awesome-agent-evolution): IDG/OODG/FR.
6. **Журнал должен иметь блок отклонённых кандидатов** (awesome-agent-evolution: отрицательные
   результаты — активы). Наш журнал односторонний.
7. **Отдельный контракт для слотов:** «ход ≠ прогон» (из прошлого слота) + «ID-контур не равен
