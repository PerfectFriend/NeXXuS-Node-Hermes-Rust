## Что конкретно в конспектах (суть)

**1. whichllm (6 795★, MIT, Python, push 2026-10-19, v0.5.21).** CLI ранжирует модели HuggingFace не по числу параметров, а по свежим бенчмаркам (LiveBench, Artificial Analysis, Aider, Chatbot Arena ELO, Open LLM Leaderboard) с учётом реального влезания и скорости. Ключевые свойства: recency-aware (устаревшие лидерборды понижаются, под рейтингом печатается дата снапшота), evidence-graded (`direct/variant/base/interpolated/self-reported` с дисконтированием по уверенности, отбраковка «наследования» скоров между семействами), архитектурный расчёт VRAM (веса + GQA KV-кэш + активации + overhead; скорость bandwidth-bound с учётом MoE active-vs-total и unified-memory vs PCIe), live-данные с HuggingFace API и вмороженные fallback-снапшоты. Флаги `--gpu/--gpu-only/--speed/--vram-headroom/--json/--markdown`, подкоманды `plan` (обратный поиск GPU), `upgrade` (сравнение апгрейдов), `run` (uv-изоляция + скачивание + чат), `snippet`. Ориентиры README: RTX 4090/3090 24 ГБ → Qwen3.6-27B Q5_K_M score 92.8 ~27 t/s; RTX 4060 8 ГБ → Qwen3-14B Q3_K_M score 71.0; CPU-only → gpt-oss-20b Q4_K_M score 45.2 ~6 t/s.
