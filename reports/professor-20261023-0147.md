## Ключевые находки для Живого Кода / SuperGuard / PXNode

1. **Superfluid = замена Ollama для роя**: preemptive scheduling (интерактив вытесняет batch), durable sessions (переживают рестарты — актуально для cron-агентов), OpenAI/Anthropic/Ollama API совместимость. Apache-2.0.

2. **AMD 780M: CPU может обгонять GPU на generation** (5.3 vs 4.5 tok/s в single-channel RAM). Ключ: HSA_OVERRIDE_GFX_VERSION=11.0.2, amdgpu.gttsize=24, power_dpm=high, MoE > dense для CPU.

3. **Mingbird: провалы маленьких моделей — вина харнесса**. 0.886 vs 0.631 (goose) на LRAB (288 cells). Методология failure form → mechanism → trade-off — прямой образец для нашего роя. Byte-level prefill budget + finish gate + loop detection.

4. **TensorFold: speculative decoding без потери детерминизма**. Row-exact kernels гарантируют byte-identical output. Gumbel noise из hash(seed, position, token) — паттерн для seeded sampling. Apple/NVIDIA only, но математика переносима.

5. **Orcanium: per-agent изоляция** (3★, ранний). Интересен паттерном event bus + per-agent memory/schedule. Не для production.
