## 3. Содержательные результаты, важные для протокола

### 3.1 magpie правит наш конфиг (риск для ядра)
В таблице README прямо указано: **Hermes Agent → `~/.hermes/config.yaml` (`$HERMES_HOME`), поле `model`**,
Hermes отнесён к provider-scoped (формат `provider/model`). Правки атомарные, gateway `127.0.0.1:3425`,
пулы аккаунтов объединяются через **routing groups** (`group/<id>`).
→ Любой внешний переключатель моделей допускать только через снапшот конфига (в графе — ребро
`kb:magpie-router → protocol:snapshot (requires)`). Сама идея routing group — готовая форма для наших пулов ключей.

### 3.2 Четыре отсутствующих у нас паттерна (Paperclip)
| Паттерн Paperclip | Наша дыра |
|---|---|
| DB-backed **coalescing-очередь пробуждений** (+ recovery осиротевших прогонов) | cron-джобы могут накладываться друг на друга |
| **atomic checkout + execution locks** по задаче | Producer/Auditor могут взять одну задачу |
| **budget hard-stop** (company/agent/project/goal/issue/provider/model) | у Hermes такого нет вообще |
| **ревизионный откат конфигов**, approval-стадии | откат делается руками |

### 3.3 `reflect` — операция, которой у нас нет (Hindsight)
retain / recall / **reflect**. У нас журнал только дописывается; никто не перечитывает его с целью получить
новые связи. Бенчмарки (сняты **с живого сайта**, в README они картинкой): **LongMemEval S 94,6%**, LoComo10 92%,
PersonaMem 32K 86,6%, LifeBench EN 71,5%, BEAM 100K 75% / 1M 73,9% / 500K 71,1% / 10M 64,1%.
Публикация подтверждена живым arXiv API: **arXiv 2512.12818** (14.12.2025). Реранкер и эмбеддинги по умолчанию —
**на CPU** (MiniLM-L6, BGE Small EN v1.5) → встраивается без GPU.

### 3.4 Инфраструктурный шаблон и красный флаг (kryvora-node)
- Забрать: **три транспорта** — Unix-сокет внутри, mutual-TLS-gRPC с heartbeat 30 с наружу, локальный REST на loopback (4177).

  Вывод: **материал разбора, не кандидат на установку**. Тот же профиль у ZCode (push 24.09 при 6856★).
