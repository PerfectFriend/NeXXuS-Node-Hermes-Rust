## 4. Анализ jobs.json и необходимые исправления

### 4.1 Выявленные проблемы в конфигурации кронов

1. **Model quota exhaustion** — 4 job'а с code 75 указывают на то, что цепочки моделей исчерпывают бесплатные квоты. Необходимо либо:
   - Добавить паузы между попытками (`restart_delay`)
   - Переключить на альтернативные модели
   - Отметить модели как `expired` до сброса квот

2. **Script path violations** — 2 job'а пытаются запускать скрипты outside `/home/thomas/.hermes/scripts/`. Нужно исправить пути.

3. **Model substitution cascades** — когда основная модель недоступна, система пробует succession моделей, что приводит к быстрому истощению квот. Рекомендуется добавлять `model_fallback` с более дешевыми моделями.

### 4.2 Предлагаемые изменения в jobs.json

```json
// Для job'ов с code 75 (пример для 9773866ed22c):
{
  "id": "9773866ed22c",
  " ... existing fields ...",
  "model_snapshot": "nvidia/nemotron-3.5-lightning-30b-a3b",  // уже установлено
  "restart_delay_seconds": 300,  // добавить паузу 5 минут между попытками
  "enabled": false  // временно отключить до сброса квот
}

// Для job'ов с script path issues:
{
  "id": "e70975dcbd0b",
  "script": "wrappers/wrapper_night_artist.sh",  // убедиться, что скрипт внутри .hermes/scripts/
  "workdir": "/home/thomas/.hermes/scripts"
}

// Для alternatif model routing:
{
  "id": "435fcd067442",
  "model_fallback": "qwen/qwen3.8-27b:free",  // добавить fallback модель
  "restart_delay_seconds": 60
}
```

## 5. Исправление промптов ролей (Role Prompt Updates)

На основе анализ ошибок предлагается уточнить инструкции в prompts(job prompts), чтобы предотвратить повторение одних и тех же ошибок:

### 5.1 Для model-heavy jobs (elemental-life, cybertarot, project4)

Добавить в prompt секцию о квотах моделей:
> ⚠️ **Внимание по квотам:** Если цепочка моделей превышает 3 попытки без успеха — останавливать и ждать сброса квот (полночь UTC). Не пробовать все модели подряд подряд, иначе все квоты будут выжжены.

### 5.2 Для night-jobbов (night-artist, night-musician)

Добавить проверку путей в prompt:
> 📋 **Проверка путей:** Убедиться, что все скрипты находятся внутри `/home/thomas/.hermes/scripts/`. Hermes блокирует выполнение скриптов outside этой директории. Использовать обертки-wrappers из `/home/thomas/.hermes/scripts/wrappers/`.

### 5.3 Для всех job'ов с доставкой в Telegram

Добавить обработку flood_control:
> 🚫 **Flood control:** При ошибке flood_control ждать exponential backoff (30s → 60s → 120s) перед повторной попыткой доставки. Не спамить мгновенно.
