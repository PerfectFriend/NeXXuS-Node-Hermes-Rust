## Изменения протокола (правила, попадающие в Учебник)
1. Изоляция веток — предпосылка параллельных кодеров. SuperGuard сейчас в одном каталоге на
   `stable-working` (одна строка `git worktree list`) — это точка приложения силы, `wt` уже стоит.
2. Merge-гейт по умолчанию закрыт: ни один автоматический конвейер не мержит без решения человека.
3. Исполнение — источник свидетельства, текст кодера — нет. Следствие для Аудитора.
4. Требования должны быть версионированным артефактом, а не перепиской — наш известный долг.
5. **Читай индекс, потом детали** (правило из claude-mem): сначала дешёвая выдача с ID,
   потом полный текст только по выборке. Применимо к чтению наших же конспектов.
6. **Лицензия проверяется по канону, а не по обзору:** за этот слот одно и то же ПО в разных
   источниках значилось AGPL-3.0 и Apache-2.0; канон — Apache-2.0.
