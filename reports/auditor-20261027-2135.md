## 4. Находки (подтверждены живыми прогонами)

### F1 — экспорт GraphML и GEXF портит метрику `degree` (самая весомая)

`p2_graph/export.py:88` и `p2_graph/export.py:158`:

```python
("degree", str(len(node.get("adjacency", [])))),
```

Ключа `adjacency` у узла **нет** — список смежности лежит на верхнем уровне графа (`graph["adjacency"]`). Поэтому `node.get("adjacency", [])` всегда даёт пустой список, и `degree` выгружается **нулём у каждого узла**.

Живой замер (граф из 3 узлов, у каждого по 2 соседа, собран через настоящий `build_graph`):

```
degree узлов:            [('te8fe5433bc14', 2), ('te8fe5433bc14-2', 2), ('te8fe5433bc14-3', 2)]
GraphML degree-значения:  ['0', '0', '0']       ← порча
GEXF degree-значения:     value="0" ×3         ← порча
JSON degree:              2, 2, 2              ← верно
NEO4J degree:             "2", "2", "2"        ← верно
PGVECTOR degree:          '2', '2', '2'        ← верно
```

В том же файле в пяти других местах (`export.py:62, 243, 311, 372, 483`) `degree` считается правильно — `len(graph["adjacency"].get(node["id"], set()))`. То есть расхождение внутри одного модуля: два формата из шести (GraphML, GEXF) молча портят метрику топологии.

Дефект не из пункта 50 — он из пункта 30 (коммит `76a60d1`, «Экспорт графа в GraphML/GEXF/JSON»), но живой и в пункте 30 `PLAN.md` стоит отметка `[x]`.

**Почему тесты его не поймали:** `tests/test_export.py:73-98, 124-136` проверяют наличие тега/структуры и наличие поля `degree` в JSON, но **не значение** `degree` в GraphML и GEXF. Слепое пятно покрытия — вторая половина этой находки.

### F2 — `cache.get` роняет команду на не-dict из pickle вместо cache miss

`p2_graph/cache.py:153-159`:

```python
try:
    graph = migrate_graph(graph)
except ValueError as exc:
    ... return None
```

Перехватывается только `ValueError`. Но `migrate_graph` на не-словаре падает `AttributeError` — `graph.get("schema_version")` не существует у списка/строки/числа. Живая проба:

```
migrate_graph([1,2,3]) → AttributeError: 'list' object has no attribute 'get'
migrate_graph('строка') → AttributeError
migrate_graph(42)       → AttributeError
migrate_graph(None)     → AttributeError
```

Второй `try/except Exception` выше (строки 141-151) ловит только ошибки чтения/распаковки pickle. Сценарий «pickle распаковался, но тип не тот» из него выскакивает и роняет команду вместо трактовки «cache miss + удалить битый кэш» — вопреки собственному docstring метода.

### F3 — миграция v1→v2 угадывает `degree=0` вместо промаха кэша

`p2_graph/schema.py:42-50`:

```python
adjacency = graph.get("adjacency") or {}
for node in graph.get("nodes") or []:
    if "degree" in node: continue
    neighbors = adjacency.get(node.get("id")) or []
    node["degree"] = len(neighbors)
```

Если `adjacency` отсутствует, все узлы молча получают `degree=0`, и граф честно помечается `schema_version=2`. Живая проба: v1-граф без `adjacency` → `degree: [0, 0]`, `version: 2`.

Это прямо противоречит принципу, заявленному в самом модуле: «неизвестная (более новая) версия НЕ угадывается — она считается неизвестной и приводит к промаху кэша, а не к догадкам». Здесь модуль догадывается — и ровно в том месте, ради которого написан.
