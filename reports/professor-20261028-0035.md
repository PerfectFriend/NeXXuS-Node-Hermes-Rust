### 2.2 LangGraph Interrupt / декларативный HITL — laya 1.5246 (метка 1.6339)
`gh api` + README + живая дока [Interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts).
- 44 005★, 7 564 forks, 498 issues, MIT, Python, создан 09.08.2023, push 27.10.2026T21:46Z.
- Механика: `interrupt({"instruction": ..., "content": ...})` — пауза, payload всплывает в `stream.interrupts`, а **возвращённое значение подставляется в состояние узла** (`return {"generated_text": edited_content}`).
- Документация прямо предупреждает: **статические (compile-time) interrupt'ы для HITL не рекомендуются** — только функция `interrupt(...)`. Плюс durable execution: возобновление ровно с места обрыва.
- **Для нас:** наш approve/reject **умеет только разрешить или отклонить** (reject — с объяснением в контекст агента). Interrupt умеет третье: **вернуть исправленный артефакт**. Для генерации кода это и есть нужная операция — «почти-верный патч» должен доезжать до merge с правкой ревьюера, а не с перегенерацией.

## 3. Сквозной вывод прохода

**Две темы — про то, чего у нас нет; две — про то, как это назвать.**
1. **Patch-слой (strix-halo):** у нас нет FA-dequant, нет KV contiguize, wave32 у нас только для RDNA3.5 (а фикс — про RDNA3.x), и стоит ровно та константа LDS-pad, которую меняет вендор. Это 4 конкретных патча, применимых к нашей 780M.
2. **HITL-операция (LangGraph):** наш гейт разрешает или отклоняет; недостаёт «вернуть исправленный артефакт» — операции, ради которой в коде-генерации гейт вообще и нужен.
3. **Граница секретов (Orca):** креды подставляет шлюз **вне** песочницы; плюс egress-admission как явный deny-list. У нас оба слоя не оформлены.
4. **Формула обучения (ruflo):** память возвращает результат в роутинг. Наш Graph-Evolution пока эволюционирует структуру, а не веса выбора.
