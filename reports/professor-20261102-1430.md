## Ключевые инсайты для Машины Кода

### 1. **Harness Engineering = 95% работы** (Aishwarya Srinivasan)
- Formula: `Agent = Model + Harness`
- Model = commodity (rent), Harness = product (build)
- Three layers: Context/Orchestration → Tools/Permissions → Eval/Observability/Feedback

### 2. **Exact verifiers before expensive judges** (ADR-050, gogo-agent, self-improving-harness)
- Run tests/typecheck/lint FIRST (free, deterministic)
- Only escalate to LLM-as-judge for semantic gaps
- Our current gates are LLM-judged → need repo-shaped exact verifiers

### 3. **Decentralized self-orchestration beats central coordinator** (Learning Self-Orchestration MPT)
- Market-based post-training: agents bid for participation
- Learned bids provide better action-training signals
- Larger populations → better performance (emergent specialization)
- **Our cron orchestrator = central coordinator (bottleneck)**

### 4. **Minimal honest harness = ~95 lines** (gogo-agent)
- Harness · Loop · Memory · Eval in one process
- Deterministic evals (56 passed in 5.53s, no API keys)
- Release gate: deterministic 100% pass, judge > threshold
- `grounded_numbers` — 90% of numbers in output must trace to tool output

### 5. **Self-improving harness without retraining** (Harness² / self-improving-harness)
- Frozen worker + capable coach editing harness
- INV editor (how it works) + DOM editor (domain knowledge)
- Probe → Compose → Select → Reflect → Library
- Blind spot: shared wrong premise → no contrast → outer loop (library) fixes it
- Weaker model + better harness > stronger model

### 6. **Extreme swarm economics** (openhuman)
- 500+ agents on $10 VPS (single Rust process)
- RLM token compression + Jev (86.8% vs 70.5% tool selection)
- D-Bus-style unified bus with lazy loading
- GPL-3.0 — license risk for embedding
