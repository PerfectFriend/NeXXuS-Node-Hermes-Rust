## Что извлечено (суть, не пересказ)

**llamastash** — Rust CLI proxy для любого локального LLM движка (Ollama, llama.cpp, LM Studio, vLLM). Единый OpenAI-совместимый интерфейс, zero overhead, terminal-native, MIT license. Ключевая ценность для Машины Коды: можно подменить `OLLAMA_HOST` на llamastash и получить единый прокси для всех движков без переписывания клиентов. Авто-детект движков, hot-reload конфига, health-check endpoints.

**GNAP** — Git-Native Agent Protocol: агенты как узлы git, обмен задачами через коммиты/ветки. Архитектура идеально выровнена с Living Code Protocol (journal.md = git log, конспекты = файлы в репо). README сохранён как `knowledge-base/gnap-spec-README.md`. Репозиторий: `gnap-protocol/gnap`. Прямая применимость: децентрализованная оркестрация роя без центрального брокера.

**TheYgent** — Two-plane архитектура: inference plane (движки, веса, реестр) + control plane (граф рантайма, реестр агентов, MCP, секреты). Control plane никогда не импортирует engine — общается через OpenAI-совместимый HTTP. Агенты = content-addressed Pydantic документы с иммутабельными версиями. Durable runtime на DBOS/Postgres: honest exactly-once recovery, idempotency keys. Критически важно для нашей устойчивости к крашам.

**Prime Agent 0.9.8** — Self-Improving Harness с Continual Harness (CRUD над состоянием харнесса), Persistent IPython REPL для интерактивной отладки, RLM (Reinforcement Learning for Models). ARC-AGI-3 95.5%. Harness эволюционирует вместе с агентом — ключевая идея для нашего RSI pipeline.

**ruflо (ruvnet/ruflo)** — Agent meta-harness для multi-player swarms с adaptive memory и RAG integration. Нативная интеграция с Hermes (в README прямо заявлено). Запускает координированные группы агентов с shared memory и collaborative solving. 606 МБ, 1057 открытых issue — зрелый проект. Одно `npx ruflo init` — и у Claude Code появляется «нервная система».
