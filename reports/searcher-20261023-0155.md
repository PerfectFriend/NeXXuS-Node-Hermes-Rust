## Ключевые находки для Машины Кода

1. **KARS** — Kubernetes-native рантайм для агентов от Azure CN Native: песочница на агента, ноль кредов внутри, брокеринг каждого внешнего вызова, AgentMesh по Signal. Имеет готовые образы `sandbox-images/hermes/` и `sandbox-images/openclaw/` с e2e тестом `hermes_openclaw_bidi.sh` — ровно наша межфреймворковая шина. Требует решение Владыки: платный Azure-провайдер или GitHub Models PAT.

2. **red-loom/loom** — независимый локальный агентный харнесс (Red Standard engine): AgentSession, provider adapters, 26 built-in tools, durable memory (Red Thread graph), MCP, subagents, patch workflow, RSAPI WebSocket engine. PyPI `red-loom`, Apache-2.0.

3. **Superfluid** — локальный LLM-сервер для multi-agent inference: приоритетная очередь (30x faster), shared prompt prefill, durable token logs, multi-device inference, llama.cpp/MLX/BaseRT под одним API. Apache-2.0.

4. **Mingbird** — local-first harness для 2–9B моделей на Ollama: 10 механизмов компенсации форм отказа малых моделей, LRAB 0.886 vs 0.631/0.479/0.405, 288 per-cell results. Apache-2.0.

5. **GPTSwarm** — оптимизация графов агентов (не только промптов), PyPI `gptswarm`, требует Python 3.11 + CPU torch (pandas 1.5.3 нет wheels на 3.12).

6. **EdgeOrchestra** — Tauri 2 + React 19 десктоп: WASM plugin sandbox, Loro CRDT agent memory, canvas memory graph physics. MIT.

7. **Self-hosted agent stack** — Pydantic AI/EngineX + LangGraph + MCP + Ragas/Promptfoo. Никаких платформных подписок. EngineX имеет Ollama path.
