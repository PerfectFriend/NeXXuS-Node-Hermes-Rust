## Что менял

Создан `internal/i18n/i18n_test.go` — первые тесты пакета, у которого до этого не было ни одного (весь переводный слой работал на доверии).

12 тестов + 2 документированных компромисса (`t.Skip` с обоснованием «почему», по прецеденту пунктов 3.3/3.4 журнала):

- `T(lang, key, args...)` — перевод на ru/es/en, фолбэк на английский при неизвестном языке, возврат самого ключа при отсутствии перевода, пустое сообщение считается отсутствующим переводом, форматирование аргументов через `fmt.Sprintf`
- `SetCustom(lang, key, msg)` — переопределение, изоляция языков (изменение ru не ломает en), создание нового языка по требованию
- `Languages()` — коды языков по умолчанию (en, ru, es)
- `NewTranslator(dataDir)` — несуществующая директория не роняет конструктор, дефолтные сообщения остаются
- `save()`/`load()` — кастомные сообщения персистятся в `i18n.json` и подгружаются при новом экземпляре; битый JSON игнорируется с дефолтами
- `T()` (глобальная обёртка) с `Global == nil` — возврат ключа без паники

## Результат мутационного тестирования

```
go run scripts/mutagen/main.go -pkg ./internal/i18n
PASS=7  FAIL=2
```

Всего мутаций: 9 (invert-comparison ×3, remove-error-check ×2, remove-function-call ×4).

**FAIL=2 — не пустые тесты, а явные компромиссы**, оформленные `t.Skip`-тестами с обоснованием:

1. `doc.go:remove-function-call#0` — мутатор задевает текст doc-комментария (`"(T, SetCustom, Languages methods)"`), а не исполняемый код. Тесты проверяют код, а не комментарии — мутация неуловима по определению.
2. `i18n.go:remove-error-check#1` — проверка ошибки `json.Unmarshal` в `load()` — защитный путь на битый JSON. При мутации наблюдаемое поведение не меняется (битый JSON → дефолтные сообщения с обеих сторон); разница только в `slog.Warn` в stderr, вне контракта `Translator`. Исправление означало бы возврат ошибки из `load()` — смена API ради теста, что запрещено правилом «не чинить то, что не сломано».

7 реальных мутаций пойманы тестами; 2 пути зафиксированы как Known Compromises — если `load()` когда-нибудь начнёт возвращать ошибку, компромисс снимается и тесты пишутся по-новой.
