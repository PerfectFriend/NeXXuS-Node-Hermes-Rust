## 2. Что извлечено (кратко, с конкретикой)

**avibe** (634★, MIT, push 2026-10-27) — «операционная система» поверх **официальных** CLI Claude Code / Codex / OpenCode (не клонов). Четыре долговечных примитива харнеса: `run`, `schedule`, `watch`, `inspect` — прямой ответ на «агент умирает, когда закрыл ноутбук». Model Hub: один ключ/подписка кормит всех трёх, протоколы переводятся между собой (GPT внутри Claude Code), автоматический **failover по квоте/429/сети** на следующий источник в маршруте, учёт токенов в официальных API-ценах + окна 5-часовых/недельных подписок. Честная оговорка README: local-first = код/данные/исполнение локально, **не обязательно веса модели**.

**Adaptive Auto-Harness** (arXiv 2606.01770v2) — декомпозиция regret: `E[Regret] = L_evo(Φ) + L_adapt(φ)`. `L_evo` — структурный потолок класса эволютора («однострочный редактор промптов не создаст многофайловую инфраструктуру»), `L_adapt` — потеря от фиксации одного харнеса **до** взгляда на задачу. Система: 4-фазный stateful эволютор (Analyze→Research→Build→Verify) с **temporal-reveal gate** (сигнал задачи только после даты резолва) и персистентным workspace → **дерево харнесов + solve-time routing** (роутер читает ветки через `git show`) → **HITL-канал** для задач, где сигнала нет в истории (ключи, новые источники). Цифры: без HITL — 97.9% PolyBench Coverage / 80.9% Accuracy / 50.2% CTF-Dojo Pass; CTF-Dojo web +27, crypto +19, **binary/pwn — 14.8% даже после всего**; routing ловит лишь часть oracle-headroom. Разложение — **аналитические** величины, не измеряемые напрямую.

**Agensh** (Microsoft, MIT, 729★, arXiv 2609.26781) — самоорганизующийся харнес **без центрального оркестратора**: цикл gather context → claim sub-task → take action → verify → merge, всё асинхронно. Gitea (workspace) + Mattermost (сообщения) + shared context из DeLM, поверх — per-agent цикл Copilot harness. ProgramBench/5 задач, GPT-5.6-sol, 6 ч без интернета: **19.31% (1 агент) → 28.78% (128)** ≈ +49% относительно; Pandoc 33.89 → 50.94 (128) → 55.06 (1024); Pandoc на GPT-6.1-sol: 56.19 → **79.59% (32 агента)**. **Рой масштабируется до ~128; дальше работает специализация, а не число.**

**Model-Harness Interactions** — рейтинги моделей **разворачиваются** между харнесами; вендорский харнес не обязан быть лучшим; цена не гарантирует результат (GPT под PI дешевле в 4 раза и выше по score). Для нас: наш харнес мутирует каждый цикл ⇒ выбор модели перепроверять, а не переносить.
