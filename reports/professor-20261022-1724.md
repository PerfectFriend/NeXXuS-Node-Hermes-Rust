## Ключевые находки для Living Code / SuperGuard

### 1. **Стек для роя агентов** (Best Frameworks + Agentful + A2A)
| Layer | Выбор | Почему |
|-------|-------|--------|
| Orchestration | **LangGraph** | Stateful graphs, checkpointing, conditional edges, cycles — MIT |
| Inter-agent comms | **A2A Protocol** | Agent Card discovery, JSON-RPC 2.0, multi-lang (Go + Python + TS) |
| Local inference | **Ollama / LM Studio** | Zero API cost, privacy, function calling + 128K context |
| Parallel execution | **Git worktrees** | Agentful pattern: independent branches, shared repo |
| Template | **Agentful v1.8.1** | Ready-made hub-and-spoke для Claude Code |

### 2. **Self-HPO = Recursive Self-Improvement для наших агентов**
- Агент **сам пишет свой harness** (H-step), потом **RL под ним** (P-step)
- Qwen3.5-35B-A3B: 57.8% → 64.8% avg SWE-Bench (+12% relative)
- **Joint gain > sum of parts** — harness и policy синергетичны
- Не требует внешней frontier модели — полностью автономный цикл
- Прямо применимо к нашему ройу: harness = SuperGuard runtime, policy = локальная Qwen на AMD 780M

### 3. **A2A = Interop слой для PXNode (Go) + SuperGuard (Python) + Dashboard (TS)**
- `/.well-known/agent.json` = service discovery без redeploy
- Push notifications для long-running tasks
- ADK `to_a2a()`, LangGraph template, Microsoft AF native support
