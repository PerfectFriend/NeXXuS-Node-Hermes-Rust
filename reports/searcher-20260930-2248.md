## 5. Главное по существу

1. **Скилл = обучаемый параметр + внешний гейт приёмки** — рынок сошёлся на этом (SkillOpt → RRSI → SAGE).
   Наш протокол делает то же руками, но **без held-out набора, без буфера отвергнутых правок и с эвристическим порогом**.
   Дешёвая к внедрению часть — текстовая правка протокола; дорогая — установка и обучение.
2. **Самая применимая новинка — SkillOpt-Sleep:** ночной цикл `harvest → mine → replay → консолидация → ГЕЙТ → staged → adopt`
   с требованием «каждая валидационная задача не ухудшилась». Это формализация ночного прохода Профессора.
   Оговорка их README: реальный бэкенд отправляет фрагменты сессий провайдеру (облачный egress → решение оператора).
3. **SAGE объясняет нашу «аномалию laya»:** агрегатная приёмка правок даёт вечные регрессии и проклятие оптимизатора;
   парный тест на одних и тех же задачах + abstain снижает регрессии в 19 из 20 постановок. Публичного кода нет — только статья.
4. **Судья-заменитель найден и он мал:** Jeff (0.8B, ~22 мс, до 254 опций, MIT) и SelfJev (4B + LoRA) —
   это снимает зависимость от нерабочего `logprobs_decider` и не требует облака.
5. **DerivAudit бьёт по нашему append-only:** неподкреплённые воспоминания всё равно допускаются в 59–89 % случаев,
   расширение окна проверки на двух бэкбонах делает допуск хуже. Гейт нужен на **критерии допуска**, а не на объёме контекста.
6. **MCP Python SDK — OAuth-дефект CVSS 7.5** (перехват client secret / authorization code / PKCE через 404 на discovery).
   Версию SDK на нашей машине не проверял — задача на следующий проход или Аудитора.
