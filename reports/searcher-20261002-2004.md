## 2. Живой аудит нашего судьи — главное

Метрики `laya-evals` берут пару `(confidence ∈ [0,1], outcome: bool)`. Это буквально наш
`answer_confidence` из `laya_bridge.py` и факт «решил ли гейт так, как золото». Ничего такого в
протоколе раньше не было — гейты держались на шкале без единого замера.

**Замер:** 16 находок из журнала, 5.5 с CPU, `routing=multilingual`.
**Золото:** моя экспертная разметка (2.0 = устранение реального дефекта, 0.5 = косметика, 0.0 = шум),
порог «существенное» = ≥1.5. *Ограничение честно: лейаблер один, это не независимое золото.*

| Метрика | Значение | Чтение |
|---|---|---|
| **AUC** | **0.3016** | ранжирование **перевёрнуто** (шум = 0.5) |
| ECE | **0.2925** | сильная дескалибровка |
| Brier | 0.2542 | — |
| kappa @1.2 | **−0.2308** | хуже независимого шума |
| acc @1.2 | 0.375 | ниже согласия по большинству |
| средний `answer_confidence` | 0.5628 | при реальной точности 0.375 → **завышает себя на ~0.19** |

Разбор по гейтам:
`≥0.8 → acc 0.438 (TP7 FP7 FN2 TN0)` · `≥1.0 → acc 0.562` · `≥1.2 → acc 0.375` · `≥1.4 → acc 0.375`

Reliability bins (n_bins=4): `conf≈0.481 → acc 0.400 (n=5)` · `conf≈0.600 → acc 0.364 (n=11)`.

**Что работает.** Выборочное предсказание по `answer_confidence` — верхний хвост полезен:
`conf ≥ 0.7129 → coverage 6.2% / accuracy 1.0` (n=1, мало) · `conf ≥ 0.6023 → cov 31% / acc 0.80` ·
`conf ≥ 0.6288 → cov 19% / acc 0.67`. **Advice для target 0.9: порог 0.7129, coverage 6.2%.**
То есть «судить по верхнему квинтилю конфиденциальности» — рабочая замена, а «score ≥ 1.2» — нет.

**Вывод, который я передаю Профессору и Владыке (решение за ними, я не меняю гейты сам):**
1. Перевести UI-гейты с `score` на порог по `answer_confidence` в верхнем квинтиле.
2. **Собрать размеченный набор 50+ находок с независимым золотом.** `n=16` мало для вывода о качестве
   модели — но достаточно для вывода «не использовать score как ворота».
3. Закрепить `laya-evals` как регресс-гейт: падение AUC < 0.5 на размеченном наборе = сигнал о смене чекпоинта.

## 3. Тренды (по laya-скору, полная раскладка — в учебнике)

**🔴 1.2+**
- **Vercel `evaluate()`** — официальный API для Jev на Python (`uv add ai`, choice/score/noul одним вызовом,
  `typesafe-ai/jev` через AI Gateway). Точка отсчёта для нашего самодельного `laya_bridge.py`.
- **Число опций задаёт порог:** XNLI (3 опции) → 0.8074, MASSIVE (20 опций) → 0.9944. Наш вопрос
  про «логично ли 1.2» закрыт: единый глобальный порог не является политикой. *(Плюс дурной сюрприз
  пакета: чекпоинт отдаёт некорректные temperature buckets для `choice:11+`.)*

**🟠 0.8–1.2**
- **Харнесс важнее модели.** GLM-5.2: 23% vs 52% на одном весе. Корреляция рейтинга харнессов между
  моделями **−0.05**. HarnessTax: Claude Fable 5 — 97.8% в Claude Code vs 96.7% в Pi, но Claude Code
  вдвое дороже ($1.33 против $0.67 за 1k). Arc-AGI-3: фронтир 30% → Prime Agent довёл Opus 5 до 95.5%.
  → Выбор харнесса парная задача; у нас свой обвяз, и он только что провалил калибровку.
- **`tracelint`** — детерминированный линтер трейсов (10★, MIT, обновлён сегодня). Критерий важнее кода:
  эти дефекты локальны структурно, поэтому модель-судья для них ненадёжна. Наш случай в точности.
- **Самоэволюция:** Proteus (вставь→эволюционизируй→измерь, любой харнесс), Google RRSI (рекурсивное
  самоулучшение харнессов), COG-second-brain (1249★, V-цикл где воркер не проверяет сам себя —
  архитектура, которой не хватает нашему журналу), Causari (Rust, причинный реестр правок как git-коммиты).
- **Безопасность:** Nuguard (красная команда, prompt injection, SBOM) — класс, который мы не покрывали.
  GitHub Security Advisory API теперь отдаёт комментарии и новые поля GraphQL → отчёты об уязвимостях
  в приватных репозиториях, применимо к мине маркеров в дереве.

**🟡 инфраструктура:** Hyperloom (AMD-AGI, автотюнинг LLM-нагрузки на AMD GPU — наша линия 780M);
Суши Core ( Ollama→облако каскадом); Vibevm (Rust, spec-driven dev); каталог `agent-infrastructure-landscape`
(912 систем, 68 колонок — сверка нашей карты знаний).

**⚪ отложено:** blogwatcher-cli дал 9 статей против 550 вчера (arXiv cs.AI на паузе, свежее из Vercel/Cloudflare/
