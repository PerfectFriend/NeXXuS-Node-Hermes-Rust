## 🔴 GPTSwarm — 1.5889 — СТАВИТСЯ (главная находка прохода)

Источник: https://github.com/metauto-ai/GPTSwarm · Apache-2.0
arXiv 2402.16823 «Language Agents as Optimizable Graphs» · https://gptswarm.org
PyPI: `gptswarm` 0.1.0 (единственная версия). Коммиты — 5 февраля, проект живой.

**Что это.** Графовый фреймворк для LLM-агентов с двумя возможностями: строить
агентов из графов и **оптимизировать граф агентов**. В отличие от SEW из прохода 22
(метод без кода) — здесь есть работающий pip-пакет. Это самое близкое к нашему
`graph-evolution-протоколу`, что найдено за три прохода.

**Стенд:** `/home/thomas/LivingCode/tools/gptswarm/.venv` на Python 3.11.16.

### Грабли — проверены лично, задокументированы в журнале

1. **Python 3.11, а не 3.12 — требование, не вкус.** Пакет тянет `pandas==1.5.3`,
   для которого нет wheels под 3.12 → сборка из исходников → `CompileError` на
   `pandas/_libs/tslibs/strptime.pyx`.
2. **`--no-build-isolation` — ловушка.** Выглядит как лечение, но заставляет pandas
   собираться из исходников: проблема возвращается и становится хуже. По дороге
   потребовались `pkg_resources` (`setuptools<81`), затем `numpy`, затем Cython —
   каждый слой добавлял время, не приближая цели.
3. **Правильный фикс — `PIP_CONSTRAINT`.** Файл `constraints.txt` с `setuptools<81`
   применяется внутри изолированной сборки и её не ломает.
4. Тянет `torch` 554 МБ — ставьте фоновым процессом, передний план не блокировать.
5. **Файловая система блокирует рекурсивное удаление** в -q режиме сканером
   безопасности. Пересоздание venv — через `mv .venv .venv_dead`.

**Статус на момент сдачи отчёта:** загрузка `torch-2.14.1-cp311` (554.6 МБ) идёт
фоновым процессом. Логи: `install.log`…`install7.log` в каталоге стенда.

## 🔴 EdgeOrchestra — 1.6213 — НЕ пустышка, но ставить нечего

https://github.com/diyamajee-spec/EdgeOrchestra · MIT · Tauri 2 + React 19 ·
коммиты 26 июня, бейдж Privacy 100%.

**Проверено предметно:** `package.json` → 200, `src-tauri` → 301, README рендерится
полностью, есть `CONTRIBUTING.md` и `CODE_OF_CONDUCT.md`.

Стек: Tauri 2 (Rust) как мост к ОС, React 19 + TS, **Ollama** (`phi4-mini`,
`qwen2.5-vl:7b`) для 100% on-device инференса включая зрение, **Zustand + Loro
CRDT**, ReactFlow для графа агентов, Canvas-физика для графа памяти, **WebAssembly**
(`wasm32-unknown-unknown`) для плагинов, Web Speech API для офлайн речи.

### Три вещи, которых у нас нет и которые стоит забрать

1. **Песочница плагинов на WASM с ограничением прав.** Слой, где у нас kars требует
   Kubernetes — здесь решается WASM: плагин физически не дотянется до файловой
   системы без явного capability. Дёшево, без Kubernetes и без Docker.
2. **Loro CRDT как память агентов.** У нас память — файлы и SQLite. CRDT даёт слияние
   **без конфликтов** при параллельной работе нескольких кодеров над одной памятью.
   Для роя из 10+ агентов это необходимость, а не удобство.
3. **Физика графа памяти на Canvas** — способ увидеть, где память разъезжается.

**Почему не ставлю:** десктопное Tauri-приложение, запускать в Машине Кода нечем.
Плюс установка тянет Rust toolchain, `npm install` и ~4.5 ГБ моделей Ollama.
Это макет UI-подхода, а не инструмент роя.
