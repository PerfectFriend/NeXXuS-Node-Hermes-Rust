## 2. Главный результат: AAB собирается. Запрос элементалей закрыт вживую

Кодер зафиксировал честный разрыв: App Bundle не собирался. **Проверка показала: Gradle-задача bundle в проекте ЕСТЬ, не хватало только ключа подписи.**

- `./gradlew bundleDebug --offline` → **BUILD SUCCESSFUL**, `android/app/build/outputs/bundle/debug/app-debug.aab` = **6 633 848 Б**, 1004 файла, подпись `C=US, O=Android, CN=Android Debug`.
- `./gradlew bundleRelease --offline` → **BUILD SUCCESSFUL**, `.../release/app-release.aab` = **5 695 809 Б**, **не подписан** (`keytool -printcert -jarfile` → `Not a signed jar file`). Причина: в `android/app/build.gradle` (Capacitor-шаблон) нет `signingConfigs`, в `release {}` нет `signingConfig` — задача `:app:signReleaseBundle` проходит вхолостую.
- **Диск не потрачен:** Gradle 8.13-all был в кэше (`~/.gradle` = 7.3 ГБ), JDK 21.0.12.1, SDK `/opt/android-sdk`, `sdk.dir` в `local.properties`. Сборка шла **offline**, сеть не использовалась.
- Артефакты выложены по конвенции: `~/apkexport/elemental-life-debug.aab` (md5 `b8d3c304584ceceabb70a80fd998b922`), `~/apkexport/elemental-life-release-unsigned.aab` (md5 `5f9d74c51c858d5e1f469f19d6113b0b`).
- **Рецепт store-ready AAB** — `knowledge-base/Android-AAB-Build-Recipe-2026.md`: upload-keystore (`keytool -genkeypair -keyalg RSA -keysize 2048 -validity 10000`), `android/key.properties` (в .gitignore), блок `signingConfigs.release`, проверка `keytool -printcert -jarfile`. Альтернатива без правки gradle: `jarsigner -keystore upload.jks app-release.aab upload`.
- **Остаток на кодере:** применить signingConfig и обновить `PORTING_REPORT.md` (запись «AAB не собран» с этого момента неверна для debug и требует ключа для release). Исходники чужих проектов я не трогал.
