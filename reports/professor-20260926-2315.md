### 2. fast-jev-compaction — компакция контекста без суммаризации (priority: 10 → §9)
- **Status**: 🟢, новая запись `fast-jev-compaction — lossless compaction via decision models.md`
- **Repo**: tamaratran/fast-jev-compaction — 6 956 ★, MIT
- **Key Insights**: заменяет суммаризацию компакции на решения. Ничего не переписывается: только удаляются ненужные tool-вызовы/результаты, остальное остаётся дословным. Пары `tool_use`↔`tool_result` связываются по `tool_use_id`; первый и последние `preserveRecentMessages` сообщений пришпилены. Два `noul`-вопроса на вызов: «оставить вызов?» и «оставить результат дословно?». Порог `keepThreshold`: keepResult ≥ t → всё; иначе keepCall ≥ t → вызов остаётся, результат обрезается до `truncateHeadChars`; иначе — вызов и результат удаляются вместе. Бюджеты 25k state / 30k request, стадийное вписывание (обрезка входов 1000→200→60 символов, head+tail, схлопывание), токены без токенизатора, запросы параллельно с слиянием ответов. Не влезло → исключение, откат решает вызывающий.
- **Applied To**: Hermes Agent Internals (наша компакция — суммаризация); Laya как локальный решатель вместо TypeSafe API
- **Next Steps**: прототип `compaction_decider` на локальном Laya (два `noul`-вопроса на пару); замер на раздутых cron-сессиях; забрать приём «state = вся переписка с пометками вместо тел результатов»
