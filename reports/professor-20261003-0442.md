## Десять правил прохода (в работу рою)

1. Поведение реализуется **инструментом**, а не просьбой в промпте.
2. Сравнивать агентов только после N повторов **одной** конфигурации (54 % — шум повтора).
3. **Консенсус не доказательство**: свидетельство — из среды; расхождение не усреднять, а разбирать.
4. **Read-back обязателен**: «исполнено» = прочитали снаружи, а не «запустили».
5. **Якорь эволюции не переписывается никогда**: переписываются харнессы задачных семейств.
6. Правка харнесса принимается **только после регрессионного теста**, а шум (δ) измеряется
   заранее повторами неизменного харнесса.
7. Локальный судья — **только за дешёвый baseline**; 4-битная квантизация его не спасёт.
8. **Триастный контракт allow / deny / no_egress**; человек — доверенный корень; enforcement до exec.
9. **Балл имеет срок годности**: хранить снимок условий у принятого изменения.
10. **Экономия токенов ≠ качество**: прирост должен окупать стоимость, но сам по себе не доказывает улучшения.

## Самое важное для нашего кода (три конкретных действия)

1. **`laya_bridge.py` — скоринг.** Наш замер (проход 11) плюс два внешних источника
   показывают: кривая точности по `score` перевёрнута (0.438 / 0.562 / 0.375 / 0.375),
   `answer_confidence` завышает себя на ~0.19. План: `decision = accept|queue|drop`
   из `answer_confidence` (порог по квинтилю, калибруемый на 50+ размеченных находках),
   `score` оставить диагностикой. CI-aware допуск вместо точечной отсечки.
2. **Инкремент роя — регуляризация по RRSI.** Перед стартом эволюции измерить δ
   повторами неизменного харнесса; добавить критик на утечку (правка с именами наших
   задач не получает балл вообще), правило оплаты приростом и pruning непродающих
   компонентов. Хранить снимок условий у каждого принятого изменения.
3. **Правила роя — прогонять по VeriSpec.** Извлечь правила с контекстом, сравнивать
   только правила одного уровня авторитета, требовать свидетельскую ситуацию. Прибор
   дешёвый ($11.12 за находку в исследовании), точность 38.5 % — применять как сканер
   кандидатов с ручной валидацией.
