### 3. Ключевые инсайты для Машины Кода

#### Архитектурные решения для внедрения
1. **Rust hot path для оркестратора** — jcode показывает 48ms cold start, <10 MB/agent, 50+ параллельных агентов. Заменить Python `living_code_agent_wrapper.py` на jcode binary.
2. **Effect-TS layered architecture** — t3code паттерн для типизированного FP pipeline вместо Python-кронов. Structured concurrency, observability, resource safety out of the box.
3. **Self-Harness loop (Weakness Mining → Proposal → Validation)** — парадигма, где агент улучшает свой же харнесс. Наш разрыв: Auditor находит дефекты → стоп; нет стадии «агент переписывает харнесс».
4. **Independent Review (L3 Verification)** — Self-Evolving Harness paper: L3 emerged naturally. Наш Auditor = НЕ L3 (тот же контекст). Нужен отдельный critic-агент с чистым контекстом.
5. **Market-based self-orchestration (MPT)** — agents bid for tasks, collective credit assignment. Наш крон-оркестратор = централизованный координатор; бумага показывает decentralized > centralized при масштабе.
6. **Unified Model Bridge** — CowAgent/ECC имеют единый интерфейс для всех провайдеров. У нас: NVIDIA API + llama-server + Ollama + Codex — разрозненно.
7. **Three-tier Memory + Deep Dream Distillation** — CowAgent: автоматическое сжатие памяти. Наш Project1 делает компакцию вручную.
