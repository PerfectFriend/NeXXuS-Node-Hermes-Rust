## Ключевые инсайты для Машины Кода

### 1. AMD 780M = Три пути (все работают)
- **Workaround** (HSA_OVERRIDE_GFX_VERSION=11.0.2): Production RAG, 54/4.5 tok/s, Ollama + ROCm 7.2
- **Native gfx1103** (ataary ollama-for-amd): Heavy prefill 290 tok/s, gen 10-14 tok/s, требует build
- **Vulkan** (vaskes/llama.cpp-rocm-780m): +20-30% vs ROCm на generation, Docker-образы с TheRock wheels
- **Real bottleneck**: Single-channel RAM (требует второй SO-DIMM модуль для 2× скорости)
- **MoE breakthrough**: Mixture of Experts обходит bandwidth bottleneck

### 2. Dynaflow = Executable Workflow Synthesis
- Main agent **writes JavaScript workflow programs** as native action
- Three modes: Direct / Dynamic (47.1% direct, 41% fewer sub-agents) / Forced
- Primitives: `agent()`, `parallel()`, `pipeline()` — sub-agents see only what script passes
- **Наш разрыв**: нет executable workflow synthesis как native action у оркестратора

### 3. dsh-purge = Reversible Config Management Pattern
- 80 host patches с per-patch status & drift detection
- Snapshot → Apply → Evidence → Revert/Rollback cycle
- Local-first, observable, reversible — **exact pattern для нашего "live config rollback"**
- Plugin layers model: each layer independently rollbackable
- **Action**: Hermes Config Snapshot/Rollback system (skill `hermes-config-backup-restore`)

### 4. ESP Mosaico = New Class of UI-Gates for Hardware Agents
- **Chat Coding** (ESP-Claw): NL → hardware prototype, no local toolchain
- **Vibe Coding** (ESP-GSP): JSON UI spec, validated at build, simulated on PC, deployed to ESP32
- **Closed-loop debugging**: Agent sees real hardware feedback, iterates
- **AG-UI compatible** — standard protocol for hardware interaction
- **Pattern transfer**: ESP-GSP JSON schema → our dashboard specs / Design tokens

### 5. OpenBot/CopilotKit = Governance Gateway Pattern
- **Governance gateway** between agent and computer — every action decided & recorded
- "A computer per agent" — isolated container, browser profile, workspace
- **AG-UI protocol** — framework-agnostic agent interface
- **Our gaps**: no per-contact isolated browser, no governance gateway, no durable thread memory, no component-based answers
