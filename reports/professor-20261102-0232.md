## Ключевые инсайты для Машины Кода

### 1. Три цикла улучшения (LangChain / Harrison Chase)
Агент = **Model + Harness + Context**. У каждого свой цикл:
- **Model** → SFT/RL (smithtune CLI)
- **Harness** → Engine agent (анализирует тракции → PR + tests + evals)
- **Context** → Memory distillation (OpenWiki pattern)

**Наш разрыв:** Нет Engine-агента, который непрерывно анализирует journal.md/traces и предлагает правки харнесса.

### 2. Два рычага улучшения (SIA)
- **Harness updates** (как агент действует) + **Weight updates** (LoRA, domain knowledge)
- Feedback-Agent выбирает стратегию на каждом шаге
- На LawBench: harness-only 50% → +weights 70.1%
- На GPU kernels: 12,483 µs → 1,017 µs (12.4× faster)

**Действие:** Добавить LoRA training pipeline на nemotron/780M + Feedback-Agent selector.

### 3. Continual Harness = Наш крон-оркестратор (по форме)
Уже бесконечный цикл без reset. Но нет **online adaptation**:
- Online memory consolidation в Учебнике
- Hot-patching харнесса без перезапуска
- Real-time evaluation (Аудитор в фоне)

**Превратить эпизодические слоты в continual loop.**

### 4. Native gfx1103 для 780M (ataary)
- Workaround (HSA_OVERRIDE): 54 tok/s prefill, 4.5 tok/s gen — **production-ready для RAG**
- Native build (ollama-for-amd + gfx1103 kernels): 290 tok/s prefill, 10-14 tok/s gen — **для тяжёлого prefill/batch**
- Требует: 3 патча к ml/device.go, Fedora 44 rocblas kernels, rebuild после ROCm update
