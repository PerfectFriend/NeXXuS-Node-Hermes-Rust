## Ключевые инсайты для Машины Кода

### 1. Теоретическая основа для надёжной самоэволюции
**A Theory of Reliable Self-Evolution** даёт **Validation Rule** — формальное условие, когда эволюционировавший харнесс можно безопасно принять. Наш цикл Профессор→Кодер→Аудитор — эмбрион этого, но **нет регрессионной проверки** на previously successful tasks.

### 2. Эталонная 5-агентная архитектура (zmy15/DeepSeek-for-VisualStudio)
Чёткое разделение: **Ask/Explore/Plan/Edit/Build** с runtime-enforced permissions, handoff protocol, plan-as-artifact. Прямо маппится на наш рой: Искатель/Профессор/Кодер/Аудитор/Владыка.

### 3. Local-first harness с learning infrastructure (ollama-agent-harness)
**Mycelium Adaptive Router** — adaptive graph learning successful tool/skill combos. **Autonomy Lead Agent** → plans task into sub-agent graph → dispatches in parallel → verifies merged result → re-plans. **Model Capability Matrix** на real autonomy runs (kimi-k2.5 cloud = first to land commit).

### 4. Self-Evolving Computer Use Agent (SEAgent)
**World State Model** (step-wise trajectory assessment) + **Curriculum Generator** (simple→complex tasks) + **Adversarial Imitation** (на failures) + **GRPO** (на successes) + **Specialist-to-Generalist distillation**. Наш разрыв: нет WSM, нет Curriculum Generator, Self-HPO только для coding.

### 5. Harness Engineering методология (basically-ai-harness)
5 pillars: **Tools + Context + Guardrails + Loop + Verify**. **Verification is non-negotiable** — guardrails alone insufficient. Mitchell Hashimoto: *"Whenever an agent makes a mistake, you engineer the environment so it won't make that mistake again."* Наш критический разрыв: **нет semantic verify step** (только test pass/fail).
