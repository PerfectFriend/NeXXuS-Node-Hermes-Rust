## Ключевые находки для Living Code / SuperGuard / PXNode

### 1. **Ollama Speech Models (Phonon TTS/STT)** — *нативный голос в Ollama 0.40.11+*
- **Источник**: https://github.com/ollama/ollama
- **Суть**: Ollama 0.40.11+ включает нативные TTS (Phonon/Gradium) и STT (Whisper). OpenAI-совместимый `/v1/audio/speech` endpoint. 35% быстрее на Apple Silicon через MLX.
- **Для Hermes**: Прямо включает локальные голосовые пайплайны — не нужен внешний TTS API. Заменит XTTS v2 / Piper в цепочке voice-processing.

### 2. **Mozilla Local LLM Benchmark 2026** — *конфигурация важнее движка*
- **Источник**: https://github.com/mozilla/llamafile
- **Суть**: Все локальные LLM движки используют llama.cpp core. Конфигурация важнее выбора движка: CUDA graphs +16.8% на L40S, Vulkan shader +63% на Steam Deck.
- **Для AMD 780M**: Критично для выбора локального LLM сервера — llama.cpp с Vulkan бэкендом даёт максимальную производительность.

### 3. **LangGraph Platform GA** — *production-ready multi-agent оркестрация*
- **Источник**: https://blog.langchain.dev/langgraph-platform-ga/
- **Суть**: Persistence, streaming, human-in-the-loop, time-travel debugging. Нативная MCP поддержка, A2A interop.
- **Для роя агентов**: Ключевая архитектура для swarm оркестрации через Hermes кроны.

### 4. **Agentic Harness Evolution (arXiv 2610.28815)** — *Successive Scale Racing (SSR)*
- **Источник**: https://arxiv.org/abs/2610.28815
- **Суть**: SSR адаптивно ищет оптимальные комбинации доказательств каждый раунд. 60% меньше валидационных прогонов. При росте пула задач 40→200 pass rate растёт 64.3%→68.3% (базлайны падают).
- **Для RSI**: Прямо применимо к evaluation harness в Living Code evolution pipeline.

### 5. **GNAP — Git-Native Agent Protocol**
- **Источник**: https://github.com/farol-team/gnap
- **Суть**: Координируй AI-агентов только через git. 4 JSON файла (agents, tasks, runs, messages). Zero infrastructure, no database. Любой агент с `git push` участвует. Git history = audit log.
- **Для Living Code**: Идеально подходит под Git-ориентированную философию проекта. Кандидат на замену/дополнение Hermes кронов.

### 6. **Headroom — context compression**
- **Источник**: https://github.com/headroomlabs-ai/headroom
- **Суть**: Сжимает tool outputs, logs, RAG chunks, files перед LLM. 20% меньше токенов для coding agents, 60-95% для JSON. Library, proxy, agent wrap (все основные агенты), MCP server. Cross-agent memory, `headroom learn` майнит неудачные сессии.
- **Для Hermes**: Прямое решение проблемы context bloat в cron-агентах. Интегрируется как proxy или MCP server.

### 7. **OKF Agent Memory** — *Git-native persistent memory*
- **Источник**: https://github.com/okf-memory/okf-agent-memory
- **Суть**: DMAA dual-layer: Push (400 токенов AAG) + Pull (OKF v0.2 knowledge/, BM25 <300µs). Pure Go, embedded MCP server, okf CLI. 100% Git-native.
- **Для Living Code**: Кандидат на второй слой памяти рядом с journal.md. Решает context bloat & memory rot.

### 8. **Swarm RSI (SwarmRSI + KSI)** — *рекурсивное самоулучшение роя*
- **Источник**: https://github.com/KSI-Protocol/ksi
- **Суть**: SwarmRSI: сотни агентов, append-only ledger, Evidence-Weighted Aggregation, 27% outperform human baseline в 48h, ℛₐᵢ=1.12. KSI: generic/stateless/disposable агенты, curated KB единственный persistent object.
- **Для Living Code**: Прямая архитектура для evolution pipeline. Noam Brown (OpenAI): 10K agents → Millennium Prize в 88h, bottleneck = GPU time.

### 9. **PreCoMem** — *Predictive Cognitive Memory*
- **Источник**: https://arxiv.org/abs/2610.29467, https://github.com/ZhongWishing/PreCoMem
- **Суть**: Memory как confidence-weighted beliefs. Effective Surprisal = semantic deviation + contradiction evidence. Три детерминированных обновления: MAINTAIN/PROFILE/CORRECT. SOTA на LoCoMo, LongMemEval-S, PersonaMem-v2.

### 10. **Agent4Sci** — *автоматизированный ML для науки*
- **Источник**: https://arxiv.org/abs/2610.28763, https://github.com/maszhongming/agent4sci
- **Суть**: 20 benchmarks/11 domains. Frontier agents улучшают published best на каждом бенчмарке (Claude Opus 10.4% mean improvement). Lightweight plug-in skills для research ideation/experiment management/checklists поднимают до 20.1%.
