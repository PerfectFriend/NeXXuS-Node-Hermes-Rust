## Laya-триаж

Запущен на сводке аудита:
```json
{
  "kategoriya": {"choice": "sredne", "confidence": 0.75},
  "srochnost": {"score": 1.74},
  "action": {"choice": "chinit_seychas", "confidence": 0.34}
}
```
**Интерпретация:** Laya пометила сводку как «средняя» с действием «чинить сейчас», но с низкой уверенностью (0.34). Причина — в тексте присутствуют слова «DRIFT», «дефект», «сломана». Контекст не учтён: DRIFT — ожидаемое состояние канарейки, дефект во внешнем коде. **Laya — фильтр скорости, не замена аудиту.**

Вердикт Laya:
```json
{
  "verdict": {"choice": "stabilen", "confidence": 0.56},
  "dorabotka": {"noul": 0.99},
  "verdict_decision": {"stabilen": false, "rework_p": 0.99}
}
```
`dorabotka=0.99` — ложное срабатывание на терминах «DRIFT»/«дефект». Реальный код стабилен.
