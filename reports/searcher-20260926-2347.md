## 3. Разведка: что горячее в AI Engineering / Programming (22–26.09.2026)

### 3.1 Agent Harness Engineering — тема окна
Термин институционализирован за считанные недели:
- **Wikipedia «Agent harness»** (новое): *agent = model + harness*; harness управляет tool use, memory, state persistence, execution environments, feedback loops; корни — ReAct (ICLR 2023) и Toolformer (NeurIPS 2023), UK AI Security Institute («модель + scaffolding», 2023).
- **Martin Fowler / Birgitta Böckeler, «Harness engineering for coding agent users»** — feedforward/feedback, computational vs inferential, steering loop, keep-quality-left, три категории: **maintainability / architecture-fitness / behaviour harness**, понятие **harnessability**, harness-шаблоны.
- **LangChain, «The Anatomy of an Agent Harness»** — компонентная матрица: system prompts; tools/skills/MCP + описания; infrastructure (filesystem, sandbox, browser); orchestration (subagents, handoffs, routing); hooks/middleware (compaction, continuation, lint).
- **firecrawl**, **Gartner («Innovation Insight: Coding Agent Harness Engineering»)**, **Artificial Analysis** — leaderboard кодящих агентов (harness меряется вместе с моделью).
- Проекты: **zai-org/ZCode** 6830★ v3.14.3 (24.09), **NVlabs/SoL-Pi** 3100★ (auto-research loops для harness'ов), **TokenRhythm/NeoHorse** 1066★ (recursive self-improvement via agentic post-training with routing harness), **CosmosMind-ai/RSI-Harness** 711★ (версионируемый harness: Pi + Genome-слой), **unreallabsai/unreal-agent** 1964★, **qiz029/dscode** 599★ (persistent shell + Ultra subagents — архитектурный аналог нашего протокола).
- **Для Живого Кода:** провести ревизию собственного harness-слоя по матрице LangChain и трём категориям Fowler. Видимые пробелы: hooks/middleware заменены ручными правилами; architecture-fitness отсутствует; «harnessability» кода не измеряется.

### 3.2 WikiSkill — академическое подтверждение архитектуры протокола

- Разделяет **сырой опыт исполнения / накопленное знание / исполняемые навыки** и непрерывно консолидирует опыт в wiki.
